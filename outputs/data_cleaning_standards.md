# 数据清洗规范库

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 系统同步说明：本文件已纳入统一数学建模生产系统。调用时默认遵循：任务路由 → 知识更新/资料入库 → 单题开工 → 数据理解 → 审题选模 → 代码/论文/图表/表格生产 → 动态验收 → 最终质量门 → 提交/答辩 → 经验回灌。涉及数据、字段、附件或参数时，先对齐 `outputs/data_cleaning_standards.md`；涉及提交、答辩或可复现判断时，先检查 `outputs/final_quality_gate.md`；缺真实数据或运行结果时，统一标为【待补】，不得编造。

## 用途
统一数学建模项目中的数据清洗、字段映射、参数整理、样本筛选与建模输入预处理规范，作为 `outputs/data_understanding_workflow.md` 和 `prompts/30_data_understanding.md` 的底层标准。

## 一、基本原则
1. 任何清洗或整理动作都要可追溯。
2. 数据、参数、规则来源都要能复述给审稿人或答辩老师。
3. 预处理服务于建模与求解，不能改变题目本身。
4. 缺失值、异常值、变量变换与参数口径必须前后一致。
5. 字段名称、论文符号、代码变量、图表标签和答辩口径必须能互相对应。
6. 没有真实数据时，只能生成模板或待补清单，不能把示例值写成真实结果。

## 二、标准流程
| 阶段 | 检查目标 | 最小记录 |
|---|---|---|
| 输入边界确定 | 明确时间、空间、对象、样本和附件范围 | 文件清单、样本范围、剔除原因 |
| 字段映射 | 把原始字段转成论文变量和代码变量 | 字段-变量-符号-单位表 |
| 缺失值处理 | 区分随机缺失、结构性缺失、不可获得参数 | 缺失比例、位置、处理依据 |
| 异常值处理 | 识别统计异常、业务异常、物理边界异常 | 识别规则、数量、保留/修正理由 |
| 单位与口径统一 | 统一量纲、时间粒度、空间粒度和统计口径 | 换算关系、聚合/拆分规则 |
| 变量与参数变换 | 标准化、归一化、对数化、平滑或编码 | 变换原因、公式、影响模型 |
| 输出交接 | 将清洗结果交给模型、表格、图示和论文 | 输入输出表、参数表、结果追溯表 |

## 三、通用检查项
### 1. 输入边界
- 明确数据来源、采集周期、样本对象和附件用途。
- 说明剔除样本、参数修正或规则筛选的原因与数量。
- 对无法获得的参数标注为“题面给定 / 数据估计 / 文献参考 / 情景设定 / 用户补入项”。

### 2. 缺失值
- 区分随机缺失、结构性缺失和不可获得参数。
- 说明删除、插补、估计或保留缺失的依据。
- 关键输入若缺失严重，应单独说明对模型成立性的影响。

### 3. 异常值
- 优先报告异常值识别规则，如 IQR、分位数缩尾、业务阈值或物理边界。
- 不要只写“删除异常值”，必须说明口径、数量和影响。
- 对可能代表真实极端情形的数据，优先保留并做稳健性检查。

### 4. 单位与粒度
- 功率/电量、金额/比例、日/月/年、个体/群体等口径不得混用。
- 时间序列必须保留时间顺序，预测任务不得随机打乱造成未来信息泄漏。
- 优化任务必须保证目标函数参数和约束参数单位一致。

### 5. 变量与参数变换
- 标准化、归一化、对数化、平滑、编码、降维都要说明原因。
- 变换后变量名称与正文、表格、代码保持一致。
- 若变换影响结果解释，论文中必须补反变换或现实含义说明。

## 四、按题型的数据清洗要求
### 1. 评价类
- 必须标注指标方向：正向、负向、适度型。
- 必须说明无量纲化方法和权重来源。
- 若评价结果后接预测、分类或优化，必须保留综合得分与后续模型输入的字段映射。

### 2. 预测类
- 必须保留时间顺序或样本划分依据。
- 训练集、验证集、测试集不能发生时间穿越或口径穿越。
- 必须报告误差指标口径，如 MAE、RMSE、MAPE、R²、Accuracy、AUC 等。

### 3. 优化类
- 必须明确决策变量、目标函数参数、约束参数和边界来源。
- 单位、上下限、初始状态、容量边界必须一致。
- 输出不能只有最优值，还要有可执行方案表和约束检查表。

### 4. 分类/识别/风险预警类
- 必须报告标签定义、样本分布、阈值来源和误判类型。
- 样本不均衡时，不能只报告总体准确率。
- 阈值不能只凭主观设定，至少要有解释或扰动检查。

### 5. 机理/仿真类
- 必须明确状态变量、参数、初始条件和边界条件。
- 参数估计要保留误差、残差或拟合优度说明。
- 单一工况结果不能直接推广到全部工况。

### 6. 工程调度/电工杯类
- 电力时间序列重点检查时间戳连续性、采样频率、重复时间点、异常突变和极端天气/节假日标记。
- 能源调度参数重点检查出力上下限、启停成本、爬坡约束、储能容量、充放电效率、电价和碳排因子。
- 工程等值参数重点检查物理量单位、合理范围、边界条件和适用工况。

## 五、P0 数据风险
出现以下情况时，不得进入 `real_case` 放行：
1. 核心字段含义不清。
2. 关键变量单位不一致。
3. 优化约束参数缺失。
4. 预测训练测试存在时间穿越。
5. 评价指标方向未处理。
6. 分类标签定义不清。
7. 关键结果无法追溯到真实数据。
8. 示例数据、演示输出或占位结果被写成真实结论。
9. 字段、论文符号、代码变量和图表标签无法对应。

## 七、论文说明段落模板
本文首先对附件数据进行字段核对、单位统一和异常记录整理。针对缺失值，按照“结构性缺失、随机缺失、不可获得参数”三类分别处理；针对异常值，结合统计规则与题目约束进行识别。处理后的变量进一步映射为模型中的状态变量、决策变量、约束参数或评价指标，并在参数表中说明其来源、单位和使用位置，以保证后续建模、求解和结果解释的一致性。
