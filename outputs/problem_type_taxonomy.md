# outputs/problem_type_taxonomy.md

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 用于沉淀数学建模题型分类体系。

每类建议记录：
- 识别信号
- 核心目标
- 常见变量
- 常见约束
- 推荐模型
- 推荐算法
- 高分表达
- 常见误判
- 答辩易被问点

---

## 1. 评价类
- **识别信号**：排序、优选、综合评分、指标体系、权重
- **核心目标**：对多个对象进行综合评价或排序
- **常见变量**：指标值、权重、评价得分
- **常见约束**：指标正向化、无量纲化、权重和为 1
- **推荐模型**：AHP、熵权法、TOPSIS、模糊综合评价、DEA
- **推荐算法**：标准化、赋权、优劣解距离、效率计算
- **高分表达**：
  - “先构建指标体系，再完成赋权与综合评价。”
  - “评价结果不仅用于排序，还用于解释不同对象的差异来源。”
  - “若单一评价模型难以同时兼顾权重、排序与效率视角，可采用职责明确的组合评价方案。”
- **常见误判**：把评价题做成预测题；只给排序不解释原因；把 PCA、因子分析等中间工具直接当最终评价结论
- **答辩易被问点**：为什么这样设指标？权重从哪来？为什么选 TOPSIS 而不是 AHP？为什么要组合多个评价模型？
- **高频子分支**：
  - **客观赋权 + 排序型**：熵权法 + TOPSIS
  - **主客观融合赋权型**：AHP + 熵权法
  - **模糊边界评价型**：模糊综合评价
  - **效率评价型**：DEA 或 DEA + TOPSIS
  - **分层后评价型**：聚类/因子分析/PCA + 综合评分

## 2. 预测类
- **识别信号**：预测、趋势、未来、需求、波动、销量、风险变化
- **核心目标**：估计未来时刻或未来区间的变量值
- **常见变量**：时间序列值、自变量、滞后项、误差项
- **常见约束**：训练数据质量、时间窗口、误差控制
- **推荐模型**：Logistic、灰色预测、ARIMA/ARMA、指数平滑、回归、BP/LSTM、随机森林回归
- **推荐算法**：参数估计、滚动预测、误差评估、训练/测试拆分
- **高分表达**：
  - “先识别序列特征，再选择与之匹配的预测模型。”
  - “通过误差指标比较不同模型的预测效果。”
  - “将预测结果进一步作为补货/调度/配置模型的输入，提高决策闭环完整性。”
  - “组合预测模型中，各模块分别承担线性趋势、非线性残差、季节项或波动结构的建模职责。”
- **常见误判**：小样本硬上深度学习；不区分趋势型、周期型、不规则型；预测结果不接后续决策；只写组合模型名称不解释分工；把 RF+GA、XGBoost+贝叶斯优化这类参数优化型组合误写成两个主预测器并列创新
- **答辩易被问点**：为什么这个模型适合该序列？误差多大？是否过拟合？预测结果如何服务后续决策？组合模型里每一部分各负责什么？
- **高频子分支**：
  - **单调饱和增长型**：Logistic
  - **小样本趋势型**：GM(1,1)
  - **线性时序型**：ARIMA / SARIMA / 指数平滑
  - **非线性回归基线型**：随机森林、BP
  - **复杂组合时序型**：ARIMA-LSTM、GM(1,1)-BP、马尔可夫链-ETS、SARIMA-GARCH

## 3. 优化类
- **识别信号**：最优、最大、最小、路径、调度、配置、分配
- **核心目标**：在约束条件下求最优方案
- **常见变量**：决策变量、目标函数值、约束参数
- **常见约束**：资源、容量、时间、预算、路径、整数限制
- **推荐模型**：线性规划、整数规划、非线性规划、多目标规划、动态规划
- **推荐算法**：单纯形法、分支定界、梯度法、GA、PSO、模拟退火
- **高分表达**：
  - “明确目标函数、约束条件与决策变量后，再选择求解算法。”
  - “模型结果直接对应可执行方案。”
  - “考虑到市场波动或需求不确定性，进一步引入情景分析、蒙特卡洛或鲁棒优化检验方案稳健性。”
  - “若单一求解器难以兼顾搜索范围与局部精度，可采用‘精确建模 + 启发式优化’或‘全局搜索 + 局部精修’的组合路线。”
- **常见误判**：只写算法不写优化模型；目标和约束不清；连续离散变量混淆；不做鲁棒性说明；离散问题直接套 PSO；存在互斥、启停、固定费用时却没有想到 0-1 变量或大 M 约束
- **答辩易被问点**：为什么选这种优化算法？结果是否全局最优？约束是否完整？如果参数波动，方案是否稳定？为什么不用整数规划而用智能算法？
- **高频子分支**：
  - **连续线性优化型**：线性规划
  - **离散/0-1 决策型**：整数规划、0-1 规划
  - **路径与巡回型**：TSP、蚁群算法、图 + 规划模型
  - **大规模非凸连续优化型**：PSO、GA、模拟退火
  - **组合优化强化型**：GA+SA、PSO+TS、SA+LP、TS+0-1 IP

## 4. 统计分析类
- **识别信号**：影响因素、显著性、关系、差异、相关性
- **核心目标**：解释变量关系并检验统计显著性
- **常见变量**：解释变量、响应变量、统计量、显著性水平
- **常见约束**：样本量、分布假设、独立性
- **推荐模型**：相关分析、回归分析、卡方检验、假设检验
- **推荐算法**：参数估计、显著性检验、残差分析
- **高分表达**：
  - “先做描述统计，再做相关或回归分析。”
  - “区分统计相关与现实因果。”
  - “若统计检验只是中间层，应继续接入分类、评价或决策模型形成闭环。”
- **常见误判**：把相关关系写成因果关系；只报显著性不解释现实意义；统计分析做到一半就停下
- **答辩易被问点**：变量选择依据是什么？显著性是否稳定？为什么统计检验足以支持后续结论？

## 5. 机理分析类
- **识别信号**：传热、受力、传播、增长、控制、系统演化
- **核心目标**：用规律解释系统变化过程
- **常见变量**：状态变量、时间、速率、边界条件
- **常见约束**：初值、边值、守恒关系
- **推荐模型**：微分方程、差分方程、系统动力学
- **推荐算法**：数值积分、参数拟合、稳定性分析
- **高分表达**：
  - “从机理规律出发建立变量之间的方程关系。”
  - “模型参数具有明确现实含义。”
  - “除拟合效果外，还需解释初值、增长率、容量上限等参数与边界条件的业务或物理意义。”
- **常见误判**：只写公式，不解释变量物理意义；把机理模型写成纯经验拟合；不解释边界条件
- **答辩易被问点**：方程怎么来的？参数怎么定？边界条件是否合理？为什么说该模型反映了真实机制？

## 6. 图论 / 网络类
- **识别信号**：最短路、连通、选址、路径、路网、节点、边
- **核心目标**：分析网络结构或求最优路径
- **常见变量**：节点、边、边权、路径长度
- **常见约束**：连通性、容量、访问顺序
- **推荐模型**：Dijkstra、Floyd、TSP、图 + 规划模型
- **推荐算法**：最短路算法、启发式搜索、贪心、局部搜索
- **高分表达**：
  - “先抽象为图结构，再定义边权与约束。”
  - “当节点规模增大或路径组合爆炸时，可引入蚁群、遗传算法等启发式搜索求近优路径。”
- **常见误判**：图结构抽象不清；边权定义主观；问题还没图论化就直接上路径算法
- **答辩易被问点**：为什么这样定义边权？为何选最短路而不是优化模型？为何需要启发式搜索？

## 7. 仿真类
- **识别信号**：仿真、模拟、场景实验、系统运行、随机过程
- **核心目标**：在复杂条件下模拟系统行为
- **常见变量**：状态、事件、概率、时间步
- **常见约束**：仿真规则、随机性、初始条件
- **推荐模型**：蒙特卡洛仿真、离散事件仿真、系统动力学
- **推荐算法**：随机采样、重复实验、场景比较
- **高分表达**：
  - “通过多次仿真比较不同方案在复杂环境下的表现。”
  - “仿真不是单独给图，而是用来检验策略在不同情景下是否稳定可行。”
- **常见误判**：仿真只展示曲线，不解释机制；把仿真当检验的全部内容
- **答辩易被问点**：仿真规则如何设定？重复次数为何足够？仿真结果如何反哺决策？

## 8. 多目标决策类
- **识别信号**：兼顾、平衡、多目标、权衡
- **核心目标**：在多个冲突目标间求折中方案
- **常见变量**：多个目标值、权重、Pareto 解集
- **常见约束**：目标冲突、资源限制
- **推荐模型**：多目标规划、NSGA-II、MOPSO
- **推荐算法**：Pareto 搜索、加权和法、演化算法
- **高分表达**：
  - “通过 Pareto 前沿刻画不同目标之间的权衡关系。”
  - “在收益、风险与可持续性之间建立可解释的折中机制。”
  - “若需进一步落地，可从 Pareto 解集中结合业务偏好选取最终执行方案。”
- **常见误判**：多个目标直接硬加权，权重没有解释；只给单个解不解释权衡过程
- **答辩易被问点**：为什么这样权衡目标？最终解如何选？有没有考虑风险和不确定性？

## 9. 时空演化类
- **识别信号**：时空分布、扩散、迁移、演变、区域差异
- **核心目标**：描述变量在时间和空间上的共同变化
- **常见变量**：时间、位置、状态量、邻接关系
- **常见约束**：空间相关性、时间连续性
- **推荐模型**：时空回归、差分/微分方程、空间统计、图网络抽象
- **推荐算法**：拟合、数值模拟、聚类或空间相关分析
- **高分表达**：
  - “同时刻画时间变化趋势与空间异质性。”
  - “在描述扩散或迁移时，应同时说明时序演变与空间邻接机制如何耦合。”
- **常见误判**：只做时间分析，不做空间刻画；只画热力图不解释传播机制
- **答辩易被问点**：空间效应如何体现？时空因素如何耦合？空间邻接关系为何这样定义？

## 10. 风险预警类
- **识别信号**：风险评分、预警、故障诊断、违约、异常识别
- **核心目标**：评估风险并给出预警机制
- **常见变量**：风险因子、阈值、分类标签、预警等级
- **常见约束**：阈值合理性、误报漏报平衡
- **推荐模型**：Logistic、随机森林、XGBoost、贝叶斯网络、AHP/熵权法、PCA
- **推荐算法**：分类训练、评分排序、阈值划分、降维压缩
- **高分表达**：
  - “风险预警不仅要识别高风险对象，还要解释风险来源。”
  - “先用 PCA 压缩高维风险特征，再进行分类或风险评分。”
  - “预警模型的价值不仅在于精度，更在于阈值分级是否可执行。”
- **常见误判**：只给评分，不建立预警分级逻辑；高维特征直接建模，不做筛选或压缩；把 PCA 结果直接当最终结论
- **答辩易被问点**：阈值怎么定？误报漏报如何平衡？为什么先做 PCA 或特征筛选？为什么该预警等级有现实意义？
