## 一、常见低分表达黑名单

### 1. 摘要区禁用表达
- “本文建立了若干模型并进行了求解。”
- “结果较好，说明模型有效。”
- “本文具有一定参考价值。”
- “通过仿真可知模型具有可行性。”
- “实验结果基本符合实际。”

### 2. 结果分析区禁用表达
- “结果如表所示。”
- “由图可知模型很好。”
- “该模型精度较高。”
- “该方案较优。”
- “各指标均有提升。”

### 3. 答辩区危险表达
- “这个模型比较常用，所以我们用了。”
- “这个算法更高级。”
- “我们参考了很多论文，感觉这个最好。”
- “时间紧，所以没有做稳健性分析。”
- “这个参数是调出来的，具体没有特别依据。”

## 二、常见低分稿特征

### 1. 审题跑偏型
**典型表现**：
- 把评价题做成预测题。
- 把优化题做成纯描述统计题。
- 把“识别风险对象”做成“给全体样本打一个综合分”。
- 只看题目关键词，不看最终输出要求。

**为什么低分**：
- 根本没有回应题目核心任务，后续模型越完整越偏题。

**纠偏方式**：
- 审题时先回答三个问题：要输出什么、按什么标准判断好坏、结果最终给谁用。

### 2. 模型堆砌型
**典型表现**：
- AHP + 熵权 + TOPSIS + 灰色关联 + 随机森林全部堆在一个评价题里。
- 预测题直接 ARIMA-LSTM-XGBoost-Transformer 全上。
- 优化题不写目标函数与约束，只展示 GA / PSO / SA 迭代图。

**为什么低分**：
- 模型之间职责不清，评委会认为“为复杂而复杂”。

**纠偏方式**：
- 每个模型都必须回答：它解决哪一层问题？如果删掉它会缺什么？

### 3. 参数优化型组合误写型
**典型表现**：
- 把 RF + GA、XGBoost + 贝叶斯优化写成两个主模型共同预测。
- 只报“创新组合名称”，不说明其实是在做超参数搜索。
- 没有基础模型基线，导致无法判断提升来自模型还是调参。

**为什么低分**：
- 职责边界写错后，评委会认为作者并不真正理解组合结构，创新点显得虚。

**纠偏方式**：
- 明确写成“预测主模型 + 超参数优化器”，并补基础模型与优化后模型的对照结果。

### 4. 只会算不会解释型
**典型表现**：
- 只给排序，不解释为什么第一名更优。
- 只给预测值，不解释趋势来源与现实含义。
- 只给最优解，不解释如何转化为可执行方案。

**为什么低分**：
- 数模竞赛不是单纯算题，结果必须能服务决策。

**纠偏方式**：
- 每个结果后都补三句话：现象是什么、原因可能是什么、对决策意味着什么。

### 5. 检验缺失型
**典型表现**：
- ARIMA 不做残差白噪声检验。
- 灰色预测不报后验差比 C 和小误差概率 P。
- AHP 不做一致性检验。
- 回归不做显著性/残差/共线性检验。
- 优化方案不做情景分析、灵敏度分析或鲁棒性测试。
- 组合模型没有基础模型对照。
- 链式建模只检验中间层，不检验最终决策方案。

**为什么低分**：
- 没有证明模型可靠，结论说服力不够。

**纠偏方式**：
- 把“模型后检验”当成正文必要章节，不是可选附录。
- 若是组合模型，必须补基础模型对照；若是链式建模，必须同时检验中间层与方案层。

## 三、常见建模误判

| 题型 | 常见误判 | 更合理做法 |
|---|---|---|
| 评价类 | 只算权重，不做综合评价 | 用熵权/AHP赋权后接 TOPSIS、模糊综合评价或 DEA |
| 预测类 | 小样本硬上深度学习 | 先试 GM(1,1)、ARIMA、指数平滑、回归等基础模型 |
| 优化类 | 不写目标函数，只写算法流程 | 先写决策变量、目标函数、约束，再谈求解算法 |
| 风险预警类 | 只给风险分数，不给阈值和分级 | 做分类/评分 + 阈值划分 + 误报漏报平衡说明 |
| 聚类/分类类 | 无监督和监督混用 | 先明确是分群还是判别，再选聚类或分类模型 |
| 机理分析类 | 只套方程不解释参数 | 必须说明参数、初值、边界条件的现实含义 |
| 时空类 | 只做时间分析，不做空间结构 | 同时处理时间趋势和空间异质性/邻接关系 |
| 链式建模类 | 中间层很多，决策层缺失 | 明确“中间层输出 → 最终决策输入”的闭环路径 |

## 四、常见算法滥用

### 1. 熵权-TOPSIS 滥用
**错误用法**：
- 不管什么题都先“熵权 + TOPSIS”。
- 指标没正向化、没标准化就直接算。
- 评价结束后没有差异来源分析。
- 只算了熵权，没有接入真正的综合评价。

**正确边界**：
- 适合多指标综合排序；不适合因果识别、预测未来、最优决策。

### 2. PSO / GA 滥用
**错误用法**：
- 小规模凸优化不用精确法，直接上智能算法。
- 离散变量问题默认用 PSO。
- 只展示迭代曲线，不解释参数设置与多次运行稳定性。
- 把近优解写成严格全局最优。

**正确边界**：
- PSO 更适合连续变量非凸优化；离散变量优先 GA、整数规划或其他离散优化方法。

### 3. PCA 滥用
**错误用法**：
- 直接把 PCA 当最终评价结论。
- 不解释保留几个主成分的依据。
- 降维后完全不解释主成分含义。
- PCA 做完后没有接分类、回归、评价或优化。

**正确边界**：
- PCA 是预处理/压缩工具，不是最终决策模型。

### 4. 随机森林 / XGBoost 滥用
**错误用法**：
- 只报精度，不解释特征重要性。
- 不做训练/测试拆分。
- 样本很少却直接上复杂集成模型。

**正确边界**：
- 适合作为非线性基线或风险识别工具，但必须保留评估与解释环节。

### 5. 模糊综合评价滥用
**错误用法**：
- 隶属函数拍脑袋设定。
- 边界清晰的题也机械套模糊评价。
- 只给等级，不解释因素如何作用。

**正确边界**：
- 适合等级边界模糊、满意度评价、风险分级等问题。

### 6. 整数规划滥用
**错误用法**：
- 明明是 0-1 决策，却不用整数变量建模。
- 用大 M 约束却不解释现实含义和取值依据。
- 只给最优值，不说明约束是否满足。

**正确边界**：
- 适合离散选择、启停、互斥、固定成本等问题，应优先于失配的连续优化算法。

### 7. Logistic 滥用
**错误用法**：
- 只因曲线平滑就套 Logistic。
- 不解释增长率和容量上限含义。
- 不存在饱和机制也硬说系统会趋稳。

**正确边界**：
- 适合存在容量上限、自限机制、先快后缓增长过程的问题。

### 8. LSTM / 深度学习滥用
**错误用法**：
- 小样本、短序列直接上深度学习。
- 只给预测图，不报测试指标。
- 不说明学习率、正则化、Dropout、梯度裁剪等训练稳定性控制。

**正确边界**：
- 适合样本充足、非线性强、长依赖结构明显的问题，且必须保留训练稳定性说明。

### 9. 组合模型滥用
**错误用法**：
- 只报 ARIMA-LSTM、GA-SA、DEA-TOPSIS 这类名字。
- 讲不清每个模块分别负责什么。
- 没有基础模型对照，无法证明改进有效。
- 只说效果更好，却不解释提升来自残差修正、排序补充还是局部精修。

**正确边界**：
- 组合模型必须围绕真实短板展开，职责和收益都要讲清。

---

### 10. 参数优化组合滥用
**错误用法**：
- 把 RF + GA、XGBoost + 贝叶斯优化写成两个主模型联合预测。
- 只强调“组合更高级”，不说明 GA / 贝叶斯优化其实是在调参。
- 没有基础模型基线，无法判断提升是否真实存在。

**正确边界**：
- 这类组合更稳妥的写法是“主模型 + 超参数优化器”，重点是证明参数优化前后性能确有改善。

## 五、论文结构与图表常见问题

### 1. 结构问题
- 摘要不写结果。
- 问题分析和模型建立脱节。
- 正文缺“模型检验”或“结果分析”。
- 结论只是重复摘要，没有升华到策略建议。
- 组合模型写进正文，但没有专门交代职责分工与改进收益。

### 2. 图表问题
- 图表只是“好看”，不服务结论。
- 图名、表名不规范。
- 图表太多，但正文不解释。
- 公式、表格、图片用截图，导致不可编辑。
- 只有收敛图、拟合图，没有任何文字说明其结论含义。

### 3. 格式问题
- 符号前后不一致。
- 公式没有编号。
- 目录和正文标题层级不统一。
- 参考文献格式混乱、年份过旧、无近5年文献支撑。

## 六、低分稿自检清单

如果一篇稿子同时出现以下任意 3 项，基本就是高风险稿：

1. 摘要没有明确结果。
2. 题型判断模糊，方法和问题不匹配。
3. 模型很多，但每个模型职责说不清。
4. 没有任何检验或稳健性分析。
5. 结果只停留在“算出来了”。
6. 没有把预测、评分接入最终决策。
7. 图表堆砌但没有解释。
8. 创新点只是“用了更复杂的模型”。
9. 参数设置没有依据。
10. 结论无法落地到管理、工程或政策建议。
11. 复杂模型没有基础模型对照。
12. 深度学习或智能优化没有稳定性说明。
13. 链式建模只写闭环口号，没有写清输入输出衔接。

---

## 七、最稳妥的改稿原则

1. 先修审题和模型匹配，再修表达。
2. 先补检验和结果解释，再谈创新包装。
3. 先让基础模型闭环，再考虑组合模型。
4. 先保证图表、公式、符号规范，再追求花哨可视化。
5. 先让论文“可信”，再让论文“高级”。
