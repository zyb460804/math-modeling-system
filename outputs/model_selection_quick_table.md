## 二、高频细分匹配补充表

| 细分场景 | 第一选择 | 升级/组合条件 | 关键提醒 |
|---|---|---|---|
| 有数据的多指标排序 | 熵权法 + TOPSIS | 若需加入局部接近度，再考虑灰色关联 | 熵权负责赋权，TOPSIS 负责排序 |
| 主客观都要兼顾的评价题 | AHP + 熵权法 | 当既要体现专家判断又要体现数据离散度时采用 | 先做 AHP 一致性检验，再解释主客观如何融合 |
| 主观判断较强的评价题 | AHP | 若想减弱主观性，可再补熵权 | 必须做一致性检验 |
| 等级边界模糊的评价题 | 模糊综合评价 | 若还需客观赋权，可再接熵权 | 隶属函数和评价集必须说清 |
| 小样本且指标冲突的评价题 | TOPSIS + 灰色关联 | 当既要全局排序又要局部稳定性时采用 | 不要把灰色关联写成简单装饰模块 |
| 多投入多产出效率评价 | DEA | 若还需综合排序，可接 TOPSIS | 效率视角和排序视角不要混说 |
| 高维识别或评分前置处理 | PCA + SVM / PCA + 分类模型 | 当特征多、相关性强时采用 | PCA 只是降维去噪，不是最终结论 |
| 小样本短序列预测 | GM(1,1) / 指数平滑 | 若存在明显非线性残差，可再考虑 GM(1,1)-BP | 先保基础趋势，再谈修正 |
| 饱和增长或扩散过程 | Logistic | 若还需政策/机制解释，可结合机理分析 | 重点解释增长率和容量上限 |
| 线性季节时序 | ARIMA / SARIMA | 若还需波动率刻画，可考虑 SARIMA-GARCH | 残差检验不能省 |
| 线性 + 非线性混合时序 | ARIMA + LSTM | 当序列既有线性主结构又有复杂非线性波动时采用 | 说明谁抓主趋势、谁修残差 |
| 非线性大样本时序 | 随机森林 / LSTM | 仅在样本充足时再上深度学习 | 要补训练稳定性与测试评估 |
| 预测模型参数较敏感 | RF + GA / XGBoost + 贝叶斯优化 | 当主模型已合适，但参数搜索空间大时采用 | 优化器负责调参，不要写成双主模型 |
| 离散选择与 0-1 决策 | 整数规划 / 0-1 规划 | 若规模太大再引入 GA / TS | 离散问题不要默认套 PSO |
| 含互斥条件或固定费用 | 0-1 规划 + 大 M 约束 | 当存在“选或不选、开或不开、二选一”逻辑时采用 | 必须解释 0-1 变量对应的业务动作 |
| 连续非凸优化 | PSO / GA / SA | 若需局部精修，可再做组合优化 | 只能宣称近优解 |
| 大规模路径/巡回问题 | TSP / 蚁群 / 图 + 优化 | 若还需局部改进，可补 ACO+Greedy 或 GA/TS | 先定义图结构与边权 |
| 全局搜索 + 局部改进都需要 | GA+SA / PSO+TS | 仅在单算法瓶颈明确时采用 | 必须说明谁全局、谁局部 |

## 三、最稳妥的选模顺序

1. 先看最终输出是什么。
2. 再看数据和约束条件。
3. 再选主干模型。
4. 最后决定是否需要辅助模型或改进。
5. 若考虑组合模型，再补问“每个模块各负责什么”。

---

## 四、最容易错配的情况

- 评价题只做赋权，不做综合评价。
- 预测题只做拟合，不做误差分析。
- 优化题只讲算法，不写目标函数与约束。
- PCA 当成最终模型。
- 链式建模只做到中间层，不进入决策层。
- 离散决策题默认套 PSO。
- 组合模型只报名字，不解释职责和对照收益。

---

## 五、最稳妥的答辩短句

- “我们先看最终输出要求，再判断题型，而不是只看表面关键词。”
- “我们优先选择能解释题目主线的主干模型，再决定是否做改进。”
- “模型选择不仅考虑能不能算，还考虑能不能检验、能不能写清、能不能落地。”
- “如果采用组合模型，我们会明确每个模块分别解决什么问题，而不是机械拼接。”
