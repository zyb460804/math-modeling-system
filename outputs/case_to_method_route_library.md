> 系统同步说明：本文件已纳入统一数学建模生产系统。调用时默认遵循：任务路由 → 知识更新/资料入库 → 单题开工 → 数据理解 → 审题选模 → 代码/论文/图表/表格生产 → 动态验收 → 最终质量门 → 提交/答辩 → 经验回灌。涉及数据、字段、附件或参数时，先对齐 `outputs/data_cleaning_standards.md`；涉及提交、答辩或可复现判断时，先检查 `outputs/final_quality_gate.md`；缺真实数据或运行结果时，统一标为【待补】，不得编造。

---

## 一、总原则

1. 先识别题目最终要什么，再决定路线。
2. 路线至少包含四件事：
   - 主模型
   - 备选模型
   - 最小检验包
   - 写作落点
3. 若题面信号和最终输出不一致，以**最终输出**为准。

---

## 二、典型路线表

| 题面信号 | 题型判断 | 主路线 | 最小检验包 | 写作落点 |
|---|---|---|---|---|
| 多指标、优选、综合评分 | 评价类 | 指标体系 + 赋权 + 综合评价 | 一致性/扰动/排序对照 | 解释谁优、优在哪里、怎么改 |
| 未来趋势、需求、销量、波动 | 预测类 | 序列判断 + 预测模型 + 误差评估 | 误差指标 + 残差/测试集 | 解释趋势、拐点、后续动作 |
| 最优、最大最小、路径、调度 | 优化类 | 变量 + 目标 + 约束 + 求解 | 可行性 + 基准对照 + 情景分析 | 解释方案结构、资源倾斜、执行建议 |
| 影响因素、显著性、关系 | 统计分析类 | 描述统计 + 回归/检验 | 显著性 + 残差/共线性 | 解释关键因素和施策优先级 |
| 风险分级、故障预警、违约预警 | 风险预警类 | 特征处理 + 分类/评分 + 阈值分级 | 分类指标 + 阈值解释 | 解释风险来源与分级动作 |
| 数据复杂且最后要给方案 | C 题链式 | 预处理 → 识别/预测/评分 → 优化决策 | 中间层检验 + 方案层稳健性 | 写清闭环和中间层如何进入决策层 |

## 三、按题型展开的作战路线

### 1. 评价类路线

#### 识别信号
- 排序
- 优选
- 综合得分
- 多指标优劣比较

#### 最稳主线
1. 建指标体系
2. 正向化、标准化
3. 确定权重
4. 做综合评价或排序
5. 解释排序差异
6. 补稳定性检验

#### 推荐组合
- 熵权法 + TOPSIS
- AHP + 熵权法
- TOPSIS + 灰色关联
- DEA + TOPSIS

#### 最小检验包
- AHP：一致性检验
- TOPSIS：权重扰动
- 评价结果：替代方法对照或秩相关比较

#### 写作落点
- 为什么这些指标能代表题目目标
- 为什么最优对象更优
- 若想改进，最该优先改哪类指标

### 2. 预测类路线

#### 识别信号
- 未来值
- 趋势
- 阶段变化
- 波动

#### 最稳主线
1. 判断序列结构
2. 选基础预测模型
3. 误差评估
4. 解释趋势与拐点
5. 若题目需要，再接决策层

#### 推荐组合
- 小样本：GM(1,1)
- 线性时序：ARIMA / 指数平滑
- 非线性基线：随机森林 / 回归
- 复杂结构：ARIMA-LSTM、SARIMA-GARCH、GM(1,1)-BP

#### 最小检验包
- 误差指标 1–2 个
- 残差/测试集说明 1 项
- 组合模型需基础模型对照

#### 写作落点
- 序列为什么适合这个模型
- 趋势意味着什么
- 预测值如何转成补货、调度、治理动作

### 3. 优化类路线

#### 识别信号
- 最优方案
- 资源配置
- 路径选择
- 调度分配

#### 最稳主线
1. 定义决策变量
2. 写目标函数
3. 写约束
4. 选择求解器
5. 解释最优方案结构
6. 做对照与稳健性分析

#### 推荐路线
- 线性结构：线性规划
- 离散变量：整数规划 / 0-1 规划
- 非线性：非线性规划
- 难精确求解：GA / PSO / SA / ACO
- 混合强化：精确模型 + 启发式搜索

#### 最小检验包
- 约束可行性检查
- 基准方案对照
- 情景分析或参数扰动
- 智能算法多次运行说明

#### 写作落点
- 为什么该方案可执行
- 资源为什么集中到这些位置
- 参数波动时方案是否还稳

### 4. 统计分析类路线

#### 最稳主线
1. 描述统计
2. 相关或回归分析
3. 显著性与诊断
4. 提炼关键因素
5. 转成施策建议

#### 最小检验包
- p 值 / 显著性
- F 检验 / 拟合优度
- 残差或 VIF 至少一项

#### 写作落点
- 哪个因素最重要
- 方向是什么
- 该优先从哪里干预

### 5. 风险预警类路线

#### 最稳主线
1. 指标或特征构建
2. 分类/评分模型
3. 阈值或等级划分
4. 高风险对象识别
5. 预警动作设计

#### 最小检验包
- 准确率之外再补召回率 / F1 / AUC
- 阈值分级依据
- 若先降维，说明 PCA 只是预处理

#### 写作落点
- 风险来源是什么
- 阈值为什么这样分
- 每一级该对应什么动作

### 6. C 题链式路线

#### 最稳主线
1. 数据清洗与预处理
2. 特征压缩 / 分类 / 评分 / 预测
3. 将中间结果接入优化或策略模型
4. 输出最终方案
5. 做情景或鲁棒性分析

#### 最小检验包
- 中间层：误差 / 分类指标 / 排序稳定性
- 决策层：可行性 + 情景分析
- 明写“中间层输出 → 决策层输入”

#### 写作落点
- 中间层为什么必要
- 决策层怎么接住中间层
- 链式方案相比只分析不决策有什么优势

### 7. 典型样本反推路线

#### 样本 A：2012A 葡萄酒评价问题
- **题面信号**：评分一致性、质量分级、理化指标解释
- **推荐主路线**：评分可靠性检验 → 指标降维/聚类 → 关系分析 → 综合评价/分级
- **备选路线**：熵权-TOPSIS 直接评价，但只有在评分可信或题目明确要求排序时再上
- **最小检验包**：评分离散性/一致性 + 聚类效果 + 排序或分级稳定性
- **写作落点**：先说明“评分是否可信”，再解释“哪些指标决定质量差异”

#### 样本 B：2015B 出租车补贴方案优化
- **题面信号**：补贴、平台策略、供需匹配、运营优化
- **推荐主路线**：供需结构识别 → 匹配指标设计 → 优化模型 → 策略输出
- **备选路线**：系统仿真 + 优化；若题目数据较弱，可先做区域分层再优化
- **最小检验包**：基准策略对照 + 等待时间/利用率变化 + 情景分析
- **写作落点**：别停在现象分析，要把结果写成平台可以执行的补贴与调度规则

#### 样本 C：电商大促销量预测（XGBoost + 贝叶斯优化）
- **题面信号**：高维特征、销量预测、自动调参、库存准备
- **推荐主路线**：特征处理 → XGBoost 基线 → 贝叶斯优化调参 → 测试集评估 → 决策应用
- **备选路线**：LightGBM / RF 基线后再做参数优化
- **最小检验包**：训练集/测试集划分 + 基线对照 + 调参前后误差比较
- **写作落点**：明确“XGBoost 是主模型，贝叶斯优化是调参器”，并把预测结果接到库存或物流决策

---

#### 样本 D：A/B/C 题的稳妥路线差异
- **A 题常见信号**：机理、物理过程、传热、传播、系统演化
- **推荐主路线**：机理分析/微分方程/规划模型优先，再补参数敏感性
- **写作落点**：重点解释假设、参数意义、边界条件和规律机制

- **B 题常见信号**：关系分析、管理策略、影响因素、方案比较
- **推荐主路线**：统计分析/评价/优化组合，强调比较分析与建议输出
- **写作落点**：重点解释差异来源、关键因素和施策优先级

- **C 题常见信号**：多源数据、复杂字段、最终要给决策方案
- **推荐主路线**：预处理 → 分类/评分/预测 → 优化/配置 → 稳健性分析
- **写作落点**：重点写清链式闭环，而不是停在数据分析层

## 四、误判预警

### 1. 评价题误判成预测题
- 表现：题目要排序，你却先预测未来值
- 修正：回到指标体系和综合评价

### 2. 优化题误判成统计分析题
- 表现：只找影响因素，不给最优方案
- 修正：把变量、目标和约束补出来

### 3. 预测题只做拟合不做解释
- 表现：报一串未来值
- 修正：解释趋势、阶段、拐点和决策含义

### 4. C 题只停在中间层
- 表现：分类或预测做完就结束
- 修正：把结果接入最终方案层

---

## 五、赛中极简调用法

1. 先一句话判断题型。
2. 立即选一条主路线。
3. 同时确定一个最小检验包。
4. 开写前先想清楚结果最终怎么落地。
