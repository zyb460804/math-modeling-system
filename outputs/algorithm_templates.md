# outputs/algorithm_templates.md

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 用于把数学建模中的高频算法沉淀成“题型—适用条件—输入输出—求解流程—论文写法—检验要点—常见风险”的算法模板库。

---

## 一、统一实战调用入口

本文件负责把“已选模型”落成可复现的算法流程，不单独承担审题、数据清洗或最终提交判断。使用时必须接入统一主链路：

**任务路由 → 知识更新/资料入库 → 单题开工 → 数据理解 → 审题选模 → 代码/论文/图表/表格生产 → 动态验收 → 最终质量门 → 提交/答辩 → 经验回灌**

推荐调用顺序：
1. 先用 `outputs/method_matching.md` 明确题型、主模型和备选模型。
2. 若算法输入依赖字段、指标、参数或附件，先用 `outputs/data_cleaning_standards.md` 固定字段映射和清洗口径。
3. 再用本文件生成算法流程、输入输出、参数说明、最低检验包和论文写法。
4. 需要代码时，接入 `prompts/19_generate_code.md` 与 `outputs/code_template_playbook.md`。
5. 需要论文、表格、图示时，分别接入 `outputs/writing_templates.md`、`outputs/table_templates.md`、`outputs/figure_templates.md`。
6. 任何“可复现”表述必须经 `outputs/reproducibility_checklist.md` 和 `outputs/final_quality_gate.md` 检查。

算法模板输出必须区分 `demo` 与 `real_case`：demo 可以给示例流程和占位参数；real_case 必须绑定真实字段、真实参数、真实运行输出和结果文件。缺失部分统一标为【待补】。

---

## 二、总原则

1. 先判断题目，再选算法；不要先想算法名。
2. 算法模板的作用是加速闭环，不是制造复杂度。
3. 每个算法至少要回答：
   - 什么时候用
   - 输入是什么
   - 输出是什么
   - 求解流程是什么
   - 论文里怎么写
   - 最低限度要补什么检验
4. 若算法不能自然进入论文闭环，就不算真正选对。

## 三、评价类算法模板

### 1. 熵权法 + TOPSIS
- **适用题型**：评价、综合排序、优选
- **适用条件**：指标较多，需客观赋权并完成排序
- **输入**：指标矩阵、指标方向
- **输出**：权重、贴近度、排序结果
- **核心流程**：
  1. 指标正向化
  2. 标准化
  3. 熵权法求权重
  4. TOPSIS 计算正负理想解距离
  5. 输出综合得分与排序
- **论文写法**：
  - “在完成指标正向化与无量纲化后，本文采用熵权法确定客观权重，并借助 TOPSIS 得到各方案的综合得分与排序结果。”
- **最低检验包**：
  - 权重扰动
  - 排序一致性比较
  - 与替代评价方法对照
- **常见误用**：
  - 不标准化就直接算
  - 权重出来后不解释
  - 排序结果不分析差异来源
- **答辩高频问法**：
  - 为什么不用 AHP？
  - 排序对权重变化敏感吗？

### 2. AHP + 模糊综合评价
- **适用题型**：评价、专家判断、带主观偏好场景
- **适用条件**：指标体系明确，允许主观判断
- **输入**：指标层次结构、判断矩阵、评价集
- **输出**：指标权重、综合等级或得分
- **核心流程**：
  1. 建层次结构
  2. 构造判断矩阵
  3. 一致性检验
  4. 确定权重
  5. 建模糊评价矩阵并综合
- **论文写法**：
  - “考虑到评价标准存在一定主观判断成分，本文采用 AHP 确定层次权重，并结合模糊综合评价完成等级判定。”
- **最低检验包**：
  - 一致性检验
  - 权重扰动
  - 结果等级稳定性
- **常见误用**：
  - 判断矩阵拍脑袋但不解释
  - 漏掉一致性检验
- **答辩高频问法**：
  - 主观性会不会太强？
  - 一致性怎么保证？

### 3. DEA
- **适用题型**：效率评价、投入产出分析
- **适用条件**：对象之间可比，投入与产出边界清楚
- **输入**：投入指标、产出指标
- **输出**：效率值、规模报酬特征
- **核心流程**：
  1. 定义投入产出
  2. 选 CCR/BCC 等模型
  3. 求效率值
  4. 解释无效对象改进方向
- **论文写法**：
  - “针对多投入多产出效率评价问题，本文采用 DEA 测度各对象的相对效率，并分析冗余与不足。”
- **最低检验包**：
  - 投入/产出指标合理性说明
  - 效率排序稳定性
- **常见误用**：
  - 把评价类指标硬塞成 DEA 投入产出
- **答辩高频问法**：
  - 为什么能把这些变量分成投入和产出？

## 四、预测类算法模板

### 4. ARIMA / SARIMA
- **适用题型**：时间序列预测
- **适用条件**：序列有较清晰线性结构，样本按时间顺序排列
- **输入**：时间序列数据
- **输出**：预测值、残差分析结果
- **核心流程**：
  1. 平稳性判断
  2. 差分与参数识别
  3. 模型拟合
  4. 预测
  5. 残差检验
- **论文写法**：
  - “在识别序列平稳性与相关结构后，本文采用 ARIMA / SARIMA 进行预测，并通过残差检验验证模型有效性。”
- **最低检验包**：
  - MAE/RMSE/MAPE
  - 残差白噪声检验
- **常见误用**：
  - 不做残差检验
  - 非线性序列也硬套
- **答辩高频问法**：
  - 为什么不用更复杂模型？

### 5. GM(1,1)
- **适用题型**：小样本趋势预测
- **适用条件**：样本少，整体趋势较平稳
- **输入**：短序列数据
- **输出**：预测值、精度等级
- **核心流程**：
  1. 累加生成
  2. 建立灰微分方程
  3. 参数估计
  4. 还原预测
  5. 后验差比与小误差概率检验
- **论文写法**：
  - “考虑到样本量较小且趋势较明显，本文采用 GM(1,1) 进行预测，并结合后验检验评估精度。”
- **最低检验包**：
  - C 值
  - P 值
- **常见误用**：
  - 波动太大还用 GM(1,1)
- **答辩高频问法**：
  - 这个模型为什么适合小样本？

### 6. 随机森林 / XGBoost
- **适用题型**：非线性预测、特征较多的回归/分类问题
- **适用条件**：样本量中等以上，希望兼顾效果与一定解释性
- **输入**：特征矩阵、目标变量
- **输出**：预测结果、重要性排序
- **核心流程**：
  1. 数据划分
  2. 训练模型
  3. 预测评估
  4. 解释关键特征
- **论文写法**：
  - “考虑到变量关系可能具有非线性特征，本文采用随机森林 / XGBoost 建立预测模型，并结合测试集指标评估泛化效果。”
- **最低检验包**：
  - 训练/测试集指标
  - 交叉验证或重复实验
  - 特征重要性解释
- **常见误用**：
  - 只报误差，不讲关键驱动因素
  - 调参后没有基线对照
- **答辩高频问法**：
  - 你怎么证明它不是过拟合？

### 7. LSTM / GRU
- **适用题型**：复杂非线性时序预测
- **适用条件**：样本较大，存在长期依赖或强非线性
- **输入**：序列样本、训练参数
- **输出**：预测结果、测试误差
- **核心流程**：
  1. 构造时间窗
  2. 模型训练
  3. 稳定性控制
  4. 测试评估
  5. 输出预测结果
- **论文写法**：
  - “考虑到序列具有明显非线性和长时依赖特征，本文采用 LSTM / GRU 建模，并通过训练稳定性控制与测试集指标保证结论可信。”
- **最低检验包**：
  - 测试集误差
  - 训练稳定性说明
  - 与基线模型对照
- **常见误用**：
  - 小样本硬上深度学习
  - 只放预测图不报误差
- **答辩高频问法**：
  - 为什么一定要用深度学习？

## 五、优化类算法模板

### 8. 线性规划 / 整数规划 / 0-1 规划
- **适用题型**：资源配置、选址、排班、路径、启停决策
- **适用条件**：目标函数与约束清楚，变量含义明确
- **输入**：目标函数、约束条件、参数数据
- **输出**：最优方案、变量取值
- **核心流程**：
  1. 定义变量
  2. 写目标函数
  3. 写约束
  4. 调用求解器
  5. 解释方案含义
- **论文写法**：
  - “考虑到决策变量本质上为离散选择，本文建立整数规划 / 0-1 规划模型描述策略组合过程，并通过求解器得到最优方案。”
- **最低检验包**：
  - 可行性检查
  - 参数扰动情景分析
  - 约束满足性说明
- **常见误用**：
  - 0-1 变量无业务解释
  - 大 M 取值随意
- **答辩高频问法**：
  - 每个 0-1 变量在现实里代表什么？

### 9. 遗传算法 / PSO / ACO
- **适用题型**：复杂优化、离散组合搜索、路径规划、非凸连续优化
- **适用条件**：精确求解难，搜索空间大
- **输入**：适应度函数或目标函数、变量边界、算法参数
- **输出**：近优解、收敛信息
- **核心流程**：
  1. 编码或初始化
  2. 迭代更新
  3. 记录最优
  4. 终止输出
  5. 多次运行比较稳定性
- **论文写法**：
  - “考虑到问题搜索空间庞大且存在非凸/离散特征，本文采用遗传算法 / PSO / ACO 搜索近优方案。”
- **最低检验包**：
  - 收敛曲线
  - 多次运行稳定性
  - 与基准方案对照
- **常见误用**：
  - 没说明编码或边权含义
  - 只给收敛图，不解释方案结构
- **答辩高频问法**：
  - 为什么智能算法适合这里？

### 10. NSGA-II
- **适用题型**：多目标优化
- **适用条件**：目标互相冲突，需要看权衡关系
- **输入**：多个目标函数、变量边界、算法参数
- **输出**：Pareto 解集、折中方案
- **核心流程**：
  1. 多目标定义
  2. 非支配排序
  3. 拥挤度维护
  4. 迭代搜索
  5. 解集筛选
- **论文写法**：
  - “针对多个目标难以同时最优的问题，本文采用 NSGA-II 搜索 Pareto 解集，并进一步结合偏好规则选取代表性方案。”
- **最低检验包**：
  - Pareto 前沿图
  - 代表方案解释
  - 情景比较
- **常见误用**：
  - 只放 Pareto 图，不给最终方案选择依据
- **答辩高频问法**：
  - 你最后为什么选这个 Pareto 点？

## 六、聚类 / 分类算法模板

### 11. K-means / 层次聚类
- **适用题型**：对象分群、用户画像、区域分类
- **适用条件**：目标是发现自然分组，不是直接预测标签
- **输入**：特征矩阵
- **输出**：类别标签、类别中心或树状结构
- **核心流程**：
  1. 标准化
  2. 选择类别数或层级结构
  3. 聚类
  4. 解释各类特征
- **论文写法**：
  - “为识别样本之间的潜在类别结构，本文采用 K-means / 层次聚类进行分群，并对各类对象的特征差异进行画像分析。”
- **最低检验包**：
  - 轮廓系数
  - 类别解释性
- **常见误用**：
  - 只分群，不说明每类意味着什么
- **答辩高频问法**：
  - 类别数是怎么选的？

### 12. Logistic 回归 / SVM
- **适用题型**：分类、风险识别、二分类判断
- **适用条件**：存在明确标签，需做分类或概率判断
- **输入**：特征矩阵、标签
- **输出**：分类结果、概率或决策边界
- **核心流程**：
  1. 数据划分
  2. 训练模型
  3. 分类评估
  4. 解释关键变量或边界
- **论文写法**：
  - “本文采用 Logistic 回归 / SVM 对样本进行分类识别，并通过准确率、召回率、F1 等指标评估模型效果。”
- **最低检验包**：
  - 混淆矩阵
  - Precision/Recall/F1/AUC
- **常见误用**：
  - 只报准确率
- **答辩高频问法**：
  - 为什么不用树模型或深度学习？

## 七、机理 / 仿真算法模板

### 13. Logistic 微分方程 / SIR / 系统动力学
- **适用题型**：传播、增长、库存演化、系统反馈
- **适用条件**：题目强调机制和演化规律
- **输入**：状态变量、参数、初值、边界条件
- **输出**：演化轨迹、稳定状态、情景结果
- **核心流程**：
  1. 变量与机制分析
  2. 建方程
  3. 参数设定
  4. 数值求解
  5. 情景分析
- **论文写法**：
  - “根据系统内变量之间的作用机制，本文建立微分方程 / 系统动力学模型刻画其演化过程，并结合参数扰动分析系统响应。”
- **最低检验包**：
  - 与历史趋势对照
  - 参数敏感性分析
- **常见误用**：
  - 只写方程不解释机制
- **答辩高频问法**：
  - 每个参数分别代表什么现实含义？

### 14. 蒙特卡洛模拟
- **适用题型**：不确定性分析、风险评估、稳健性测试
- **适用条件**：关键变量存在随机波动，需要看结果区间
- **输入**：随机变量分布、样本次数、评价指标
- **输出**：结果分布、置信区间、情景结果
- **核心流程**：
  1. 设定随机变量分布
  2. 重复采样
  3. 计算指标
  4. 汇总分布与区间
- **论文写法**：
  - “考虑到关键参数存在不确定性，本文采用蒙特卡洛模拟评估方案在随机波动环境下的表现。”
- **最低检验包**：
  - 采样次数说明
  - 分布结果图
  - 关键指标区间解释
- **常见误用**：
  - 不解释分布假设来源
- **答辩高频问法**：
  - 为什么这样设随机分布？

## 八、链式建模算法组合模板

### 模板 A：预处理 → 评价
- **典型组合**：标准化 / PCA → 熵权法 → TOPSIS
- **适用场景**：高维评价排序
- **关键写法**：
  - “前一层用于消除尺度差异与冗余，后一层完成权重确定与综合排序。”
- **最低检验包**：
  - PCA 解释方差
  - 权重扰动
  - 排序一致性

### 模板 B：预处理 → 预测 → 优化
- **典型组合**：清洗 / 特征处理 → RF/XGBoost/LSTM → 规划模型
- **适用场景**：需求预测、补货、调度、库存配置
- **关键写法**：
  - “预测层输出被进一步写入目标函数与约束，形成‘预测—决策’闭环。”
- **最低检验包**：
  - 预测误差
  - 方案情景分析
  - 链式衔接解释

### 模板 C：评分 → 分级 → 决策
- **典型组合**：评价模型 → 阈值分级 → 治理/配置策略
- **适用场景**：风险预警、优先级治理
- **关键写法**：
  - “中间层得分结果进一步转化为等级划分与资源优先级规则。”
- **最低检验包**：
  - 分级阈值合理性
  - 分级结果稳定性

## 九、低分高风险信号

- 一上来就报算法名，不先解释题型
- 算法很多，但没有主从关系
- 中间层输出没有进入后续层
- 只讲求解过程，不讲结果如何解释
- 没有检验或检验流于空话
- 深度学习或智能优化只显得复杂，没有真实增益
