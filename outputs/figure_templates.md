# outputs/figure_templates.md

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 用于沉淀数学建模论文与答辩中的高频图示模板，统一“图名—用途—结构—放置位置—正文配套写法—常见风险”。

---

## 一、统一图示生产入口

本文件负责把题目拆解、模型结构、算法流程、结果对比和答辩主线压缩成图示。图示必须解释建模逻辑，而不是装饰版面，并接入统一主链路：

**任务路由 → 知识更新/资料入库 → 单题开工 → 数据理解 → 审题选模 → 代码/论文/图表/表格生产 → 动态验收 → 最终质量门 → 提交/答辩 → 经验回灌**

推荐调用顺序：
1. 先用 `outputs/method_matching.md` 明确题型和模型路线，避免图示先行导致逻辑跑偏。
2. 若图中包含字段、指标、参数或结果数字，先用 `outputs/data_cleaning_standards.md` 和 `outputs/table_result_alignment_workflow.md` 核对口径。
3. 用本文件选择技术路线图、链式闭环图、模型结构图、算法流程图、结果图或答辩压缩图。
4. 图名、变量、模块名必须与论文正文、代码变量和表格列名一致。
5. 提交或答辩前用 `outputs/final_quality_gate.md` 检查图表编号、数字来源和图文一致性。

缺真实结果时，只能生成图示草图、结构图或占位图，不得把 demo 图写成真实结论图。

---

## 二、总原则

1. 图示模板的目标是加快表达，不是堆视觉效果。
2. 每张图都要回答三个问题：
   - 为什么要画？
   - 画给谁看？
   - 看完后应理解什么？
3. 论文图与答辩图可以同源，但密度不同：
   - 论文图更完整
   - 答辩图更压缩
4. 同一张图最好只承担一个主任务。

---

## 二、统一模板字段

后续设计每张图时，尽量统一写出：
- **图名**
- **用途**
- **适用场景**
- **标准结构**
- **建议布局**
- **建议放置位置**
- **正文前置句**
- **图后解释句**
- **常见风险**

## 三、核心图示模板

### 模板 1：技术路线图
- **图名**：本文技术路线图 / 整体建模流程图
- **用途**：一图讲清全文从题目到结果的主线
- **适用场景**：几乎所有论文与答辩
- **标准结构**：
  - 输入层：题目 / 数据 / 约束
  - 处理层：预处理 / 问题分析
  - 模型层：主模型 / 子模型
  - 检验层：误差 / 稳健性 / 情景分析
  - 输出层：结果 / 建议
- **建议布局**：从左到右或从上到下，单主线最稳
- **建议放置位置**：问题分析后、模型建立前；答辩第 2–3 页
- **正文前置句**：
  - “为便于说明本文整体求解思路，现给出技术路线图如下。”
- **图后解释句**：
  - “该图展示了从题目输入到结论输出的完整路径，其中【模块】是连接前后层的关键。”
- **常见风险**：
  - 把章节标题直接堆成图
  - 没有输入输出关系

### 模板 2：题目拆解图
- **图名**：问题结构与任务拆解图
- **用途**：说明题目究竟要求解决哪些子任务
- **适用场景**：多问题题目、业务型 C 题
- **标准结构**：题目目标 → 子问题 → 对应输出 → 关键约束
- **建议布局**：中心放总任务，四周展开子问题
- **建议放置位置**：问题重述后
- **正文前置句**：
  - “为避免后续建模偏离题意，先将题目任务结构化拆解如下。”
- **图后解释句**：
  - “由图可见，本文核心并非单一预测/评价，而是围绕【主任务】展开的多阶段求解问题。”
- **常见风险**：
  - 只抄题面，不提炼目标和约束

### 模板 3：链式建模闭环图
- **图名**：链式建模闭环结构图
- **用途**：说明中间层结果如何进入最终决策层
- **适用场景**：预测→优化、评分→决策、分类→治理
- **标准结构**：
  - 前端层：预处理 / 分类 / 预测 / 评分
  - 中间层输出：预测值 / 得分 / 标签 / 风险等级
  - 决策层：优化 / 配置 / 治理
  - 结果层：方案 / 建议 / 检验
- **建议布局**：水平串联最稳，中间层单独高亮
- **建议放置位置**：模型总体思路部分；答辩主线页
- **正文前置句**：
  - “考虑到本文采用多阶段求解框架，现用一张图说明各层之间的输入输出关系。”
- **图后解释句**：
  - “该图的关键不在于步骤罗列，而在于说明中间层结果如何真正支撑最终方案。”
- **常见风险**：
  - 前后各写各的，没有中间层箭头

### 模板 4：模型结构图
- **图名**：模型结构示意图 / 系统结构图
- **用途**：展示模型内部模块组成与关系
- **适用场景**：机理模型、系统动力学、复杂评价体系
- **标准结构**：模块 A / B / C + 连接关系 + 输入输出
- **建议布局**：中心主模块，周围子模块
- **建议放置位置**：模型建立部分
- **正文前置句**：
  - “为说明模型内部变量与模块之间的关系，构建结构示意图如下。”
- **图后解释句**：
  - “由图可见，模型并非简单堆叠，而是由【模块】共同作用于【目标变量】。”
- **常见风险**：
  - 模块命名与正文不一致

### 模板 5：算法流程图
- **图名**：算法求解流程图
- **用途**：解释算法步骤与迭代逻辑
- **适用场景**：GA、PSO、ACO、动态规划、复杂流程求解
- **标准结构**：输入 → 初始化 → 核心迭代 → 判断 → 输出
- **建议布局**：纵向最稳，判断节点用菱形
- **建议放置位置**：算法设计部分
- **正文前置句**：
  - “为说明求解过程，现给出算法流程图如下。”
- **图后解释句**：
  - “该流程图说明了模型如何从输入参数逐步迭代到最终解，并给出停止条件。”
- **常见风险**：
  - 流程图过细，像代码截图
  - 漏掉输入、输出或终止条件

### 模板 6：变量关系图
- **图名**：变量作用关系图 / 机制图
- **用途**：解释变量之间的影响路径
- **适用场景**：回归、机理分析、系统演化
- **标准结构**：自变量 → 中介变量 → 因变量；可配正负影响箭头
- **建议布局**：从左到右，因果链清晰
- **建议放置位置**：模型假设或机理分析部分
- **正文前置句**：
  - “在建立模型前，先梳理关键变量之间的作用路径。”
- **图后解释句**：
  - “该图说明【变量 A】并非直接决定结果，而是通过【路径】影响【变量 B】。”
- **常见风险**：
  - 箭头太多，主路径不清

### 模板 7：数据处理流程图
- **图名**：数据预处理流程图
- **用途**：说明数据从原始态如何进入模型
- **适用场景**：字段多、清洗复杂、特征处理明显时
- **标准结构**：原始数据 → 缺失/异常处理 → 标准化/编码 → 特征筛选 → 建模输入
- **建议布局**：线性流程最稳
- **建议放置位置**：数据预处理部分
- **正文前置句**：
  - “为保证建模输入质量，本文先对原始数据进行如下处理。”
- **图后解释句**：
  - “通过上述流程，原始数据被转化为满足后续模型要求的标准输入。”
- **常见风险**：
  - 只写“清洗”“标准化”，不说对象和目的

### 模板 8：结果对比图
- **图名**：方案对比结果图 / 基准与改进方案对比图
- **用途**：展示改进是否真实有效
- **适用场景**：优化题、组合模型、改进模型
- **标准结构**：基准方案 vs 改进方案 vs 扰动情景
- **建议布局**：柱状图、折线图或组合图
- **建议放置位置**：结果分析部分
- **正文前置句**：
  - “为验证改进方案的实际效果，将其与基准方案进行对比。”
- **图后解释句**：
  - “由对比结果可见，改进方案在【指标】上具有更明显优势，说明新增模块并非单纯增加复杂度。”
- **常见风险**：
  - 没有基准对照对象

### 模板 9：稳健性 / 灵敏度图
- **图名**：模型稳健性分析图 / 参数扰动结果图
- **用途**：证明关键结论稳定
- **适用场景**：评价、预测、优化、机理题均适用
- **标准结构**：参数扰动 / 情景变化 → 结果波动
- **建议布局**：折线图、箱线图、情景柱状图
- **建议放置位置**：模型检验部分
- **正文前置句**：
  - “为检验模型对关键参数变化的敏感程度，进一步进行灵敏度分析。”
- **图后解释句**：
  - “在合理扰动范围内，关键结论保持基本稳定，说明模型具有较好的稳健性。”
- **常见风险**：
  - 只给图，不说明扰动范围与业务意义

### 模板 10：答辩压缩总图
- **图名**：模型与结果总览图 / 一图讲清全文
- **用途**：供答辩时快速压缩表达
- **适用场景**：5 分钟答辩、总结页
- **标准结构**：题目 → 主模型 → 核心结果 → 检验 → 创新点
- **建议布局**：横向五段式最稳
- **建议放置位置**：PPT 开场或结尾
- **正文前置句**：
  - 不建议放论文正文，主要服务答辩
- **图后解释句**：
  - “若将全文压缩为一页，本图展示的就是最核心的题目—模型—结果—检验逻辑。”
- **常见风险**：
  - 内容太满，失去压缩价值

## 四、按题型推荐优先图示

### 1. 评价题
优先：
- 指标体系图
- 排名对比图
- 雷达图
- 稳健性扰动图

### 2. 预测题
优先：
- 历史—预测趋势图
- 误差对比图
- 关键阶段放大图
- 特征重要性图

### 3. 优化题
优先：
- 技术路线图
- 约束结构图
- 方案对比图
- 情景分析图

### 4. 机理 / 仿真题
优先：
- 变量关系图
- 系统结构图
- 演化趋势图
- 参数扰动图

### 5. 链式题
优先：
- 链式建模闭环图
- 中间层结果图
- 最终方案图
- 稳健性图

## 五、图示布局建议

### 1. 最稳布局
- 单主线：从左到右
- 分层结构：从上到下
- 中心扩散：中心节点 + 四周模块

### 2. 节点数量建议
- 论文图：5–9 个核心节点最稳
- 答辩图：4–7 个核心节点最稳

### 3. 颜色建议
- 论文：2–3 种主色即可
- 答辩：核心节点可高亮，但不要彩虹化

## 六、正文配套模板

### 图前引导句
- “为更直观说明……，现给出……图。”
- “考虑到本文涉及多阶段求解，先用图示概括整体思路。”
- “在进入公式推导前，先梳理变量与模块之间的关系。”

### 图后解释句
- “该图的关键在于说明……而非重复正文步骤。”
- “从图中可见，……因此后续模型建立围绕该主线展开。”
- “图示结果从结构上支撑了后文的求解与分析。”

---

## 七、最常见低分风险

- 图名太空泛
- 图中元素过多
- 节点之间没有箭头逻辑
- 图与正文术语不一致
- 图前不引、图后不解
- 把答辩图直接塞进论文而不压缩
- 只追求炫酷效果，不支撑核心结论
