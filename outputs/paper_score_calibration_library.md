# 优秀论文评分校准库

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 本文件用于把真实论文、修改稿和优秀作品中的高分信号回灌到 `outputs/scoring_rubric.md`。它不替代统一评分表，只用于校准 85 分、90 分、95 分边界。

---

## 一、校准原则

1. 评分仍以 `outputs/scoring_rubric.md` 的 100 分主表为唯一标准。
2. 优秀论文样本不用于新增独立分项，只用于解释“什么样的表现可以给高分”。
3. 校准重点不是模型名称，而是审题主线、模型闭环、检验证据、结果落地和写作成熟度。
4. 同一篇论文若模型复杂但职责不清、检验不足或结果不落地，不得因为模型名称高级而上调分数。
5. 真实修改稿用于校准 P0/P1/P2 优先级：先看论文是否成立，再看是否冲高分。

## 三、样本校准卡片

### 1. 高血脂风险预警与干预决策稿

**题型定位：** 链式综合题，包含关键指标筛选、三级风险预警、个体化干预优化。

**高分信号：**
- 审题没有把题目简化成单一分类任务，而是识别为“筛选—预警—优化”的完整健康管理链条。
- 问题 1 明确区分痰湿偏颇解释与高血脂风险预警，采用双目标特征筛选，避免只围绕标签恢复。
- 问题 2 没有强行生造三分类监督标签，而是构造连续风险指数并结合 CART 规则提取，解释性较强。
- 问题 3 使用字典序离散优化，避免综合效用权重主观化，能还原为具体干预方案。
- 摘要中写出了关键结果、模型检验和样本方案，符合强终稿摘要标准。
- 对 0.997 准确率保持克制解释，指出高一致性来自标签与血脂阈值结构，不把漂亮数值包装成模型先进。
- 有交叉验证、AUC、敏感性分析和预算扰动，可信度较强。

**可作为 90+ 边界的原因：**
- 主线完整，三问之间存在明确输入输出关系。
- 结果不仅报数，还解释了体质变量、代谢指标和干预方案的现实含义。
- 能主动承认样例数据限制和经验参数风险，答辩边界较稳。

**仍需警惕的扣分点：**
- 若正式比赛中缺少真实随访数据，干预改善率属于经验参数，应在答辩中明确其来源和敏感性。
- 医学结论不能越界外推，应限定为样例数据下的统计建模结果。

**回灌规则：**
- 链式题高分必须能说清“识别结果如何进入分层，分层结果如何进入决策”。
- 漂亮准确率只有在解释其来源、局限和用途后才是加分信号。
- 优化题若权重争议较大，可以优先考虑字典序、约束优先或分层决策表达。

### 2. 五一 C 题边坡预警初稿

**题型定位：** 工程预警类链式综合题，包含传感器校正、阶段识别、多源异常检测、预测补全和速度阈值预警。

**高分信号：**
- 能把五个问题统一为“数据校正—阶段识别—多源清洗—分阶段预测—速度预警”。
- 问题重述和问题分析能指出本题不是单一预测，而是数据质量、阶段转换和多源扰动解释的综合题。
- 使用速度持续性而非单点突变识别阶段，贴合边坡失稳机理。
- 表格结果较完整，包含 RMSE、MAE、R²、阶段速度、异常点统计和阈值。
- 预警结果能转化为黄色、橙色、红色阈值及建议措施。

**主要短板：**
- 部分结果高度依赖模型输出，但对时间序列验证方式、外推能力和阶段间连续性解释不够强。
- 异常检测中孤立森林异常比例偏高时，需要解释污染率或阈值设定，否则评委会质疑过检。
- 工程预警阈值虽然有分位数依据，但还需要和阶段速度、误报控制、响应动作形成更强闭环。

**对应阶段：** 可提交稿到强终稿之间。

**回灌规则：**
- 工程预警题不能只给预测值，必须给预警等级、触发条件和处置动作。
- 阶段识别题高分关键是区分“持续趋势变化”和“瞬时扰动”。
- 异常检测数量异常偏大或偏小，都需要解释检测阈值和工程含义。

### 3. 五一 C 题新版论文

**题型定位：** 工程多源监测与分阶段预警。

**高分信号：**
- 摘要比初稿更像成品，按任务顺序给出方法、关键数值和结论。
- 问题分析中明确每一问的本质：传感器校准、非平稳分段、异常诊断、分阶段建模、变量组合与预警。
- 模型假设、符号说明、模型建立、结果表格、图示引用较完整。
- 阈值预警部分同时说明统计依据和工程含义，能够服务实际预警。
- 模型评价中主动指出随机交叉验证可能不适合非平稳时序，这是答辩中很重要的边界意识。

**主要短板：**
- 对时间序列任务，若使用随机五折交叉验证，需要补充时间顺序验证或滚动验证，否则可能被质疑信息泄漏。
- 问题 5 的 R² 较低时，应更强调变量受限和预警阈值用途，而不是把预测效果包装成很强。
- 阶段模型之间预测跳跃需要解释或补连续性约束。

**对应阶段：** 强可提交稿。

**回灌规则：**
- 非平稳时序题的强终稿应优先采用时间顺序验证、滚动验证或外推检验。
- 若某一子模型效果不强，不能掩盖，应解释变量限制、任务目的和使用边界。
- 工程类论文的“不足”不能只写泛泛未来工作，应指向外推、阈值迁移、阶段连续性等真实风险。

### 4. 五一 C 题评委意见修改版

**题型定位：** 工程预警类强终稿校准样本。

**高分信号：**
- 摘要给出完整模型链条、关键数值和预警规则，信息密度高。
- 采用 Huber 鲁棒回归、MAD/Hampel 异常检测、时间序列交叉验证、速度聚类阈值，比普通机器学习堆叠更贴合工程数据特征。
- 对不同变量采用不同预处理方式，体现了变量属性意识：连续变量插值和平滑，脉冲变量保留事件特征。
- 问题 4 使用“阶段趋势项 + 扰动残差修正项”，比单一黑箱预测更有工程解释力。
- 问题 5 同时考虑预测误差和机理完整性，避免只按误差最小机械选变量。
- 增加敏感性与鲁棒性检验，覆盖 Huber 参数、SG 窗口、变点窗口、速度聚类初值和输入噪声。
- 预警规则含连续触发和多源同步条件，能降低单点噪声误报。

**可作为 95 分边界参考的原因：**
- 主线闭环完整：校正可信数据 → 识别阶段 → 清洗多源数据 → 预测位移 → 生成预警动作。
- 模型选择贴合工程对象，不是算法堆砌。
- 检验包完整，既有误差指标，也有参数扰动、噪声扰动和阈值稳定性。
- 结果可直接转化为工程响应规则，落地性强。
- 不足部分能具体指向外推能力、阶段样本量、场地阈值标定等真实风险。

**仍需注意：**
- 若文中出现队伍、学校、姓名、联系方式等信息，正式论文正文必须删除或只保留在承诺书页。
- 如果附件数据的指定结果与题面标准答案或格式要求有差异，需要严格按赛题提交要求整理。

**回灌规则：**
- 工程类 95 分稿必须同时满足对象闭环、约束闭环、检验闭环和表达闭环。
- 鲁棒性检验不是泛泛写“模型稳定”，而要列出扰动对象、扰动幅度、核心结果变化和结论。
- 工程预警规则高分写法应包含：指标、阈值、连续触发条件、辅助变量、预警等级和处置动作。

## 四、分数边界校准

### 1. 85 分边界：强可提交稿

应满足：
- 题型判断正确，主模型没有跑偏。
- 每问都有结果，摘要能写出关键数值。
- 至少有一种核心检验，如交叉验证、误差指标、权重扰动、约束核查或情景分析。
- 结果能回应题目，但解释深度、边界意识或图表组织仍可提升。
- 代码或求解流程基本可复现，但不一定完全形成提交包闭环。

典型风险：
- 结果能看，但检验不够厚。
- 图表有，但正文解释不足。
- 模型可用，但替代方法比较和答辩边界较弱。

### 2. 90 分边界：高质量终稿

应满足：
- 问题分析准确，能说明为什么不是简单套模型。
- 模型链条自然，每个子模型都有明确职责和输入输出衔接。
- 摘要、正文、图表、结论的关键数值一致。
- 结果分析能做到“结果是什么—为什么这样—对决策意味着什么”。
- 至少有一组硬检验和一组稳健性 / 敏感性分析。
- 不足部分能承认真实边界，不做过度外推。

典型加分信号：
- 能解释漂亮指标背后的原因，而不是只炫数值。
- 能把预测、评价或识别结果转化为方案、规则或行动建议。
- 能说明复杂模型相对基础方案补了什么短板。

### 3. 95 分边界：冲奖稿

应满足：
- 主线极清楚，摘要读完即可知道对象、方法、关键结果、检验和价值。
- 模型不是堆叠，而是围绕题目机制形成自然分层。
- 检验完整，包括误差、扰动、基准、情景、约束核查或多次运行稳定性中的多项证据。
- 结果高度落地，能还原为风险等级、调度方案、干预方案、预警动作或工程参数。
- 图表服务结论，每张关键图都回答一个具体问题。
- 答辩能讲清选模理由、替代方案、模型边界和创新点补了什么短板。

典型减分门槛：
- 没有模型检验，不能到 90。
- 关键数字不可追溯，不能到 85。
- 结果不能转化为行动或结论，不能到 90。
- 复杂模型职责不清，不能因模型高级冲到 95。

## 五、对评分表的回灌建议

1. 在 `outputs/scoring_rubric.md` 中补充“真实样本校准边界”：85 / 90 / 95 分分别对应什么稿件成熟度。
2. 在工程预警类快速评分卡中强化：连续触发、多源同步、处置动作和阈值迁移边界。
3. 在时序预测和工程监测题中强化：随机交叉验证不一定足够，应优先补时间顺序验证或滚动验证。
4. 在链式综合题中强化：中间模型必须进入后续分层、优化、预警或决策。
5. 在鲁棒性评分中强化：扰动对象、扰动幅度、结果变化和结论必须成表。

### 5. 2012 国赛 A 题：基于排序检验的葡萄酒评价

**来源文件：** `outputs/extracted_pdf_text/2012国赛国家一等奖A题优秀论文2.txt`  
**材料类型：** 国赛国家一等奖优秀论文  
**题型：** 评价类 / 统计检验 / 指标排序 / 相关分析

**论文主线：**
- 问题 1：把两组评酒员评分转化为秩次和秩和，用 Wilcoxon 符号秩检验判断显著性差异，再用组内方差与理想排序方差判断可信组别。
- 问题 2：以质量最高样本为理想点，筛选与香气评分相关的芳香物质，结合葡萄理化指标，用 TOPSIS 接近度和秩和排序对葡萄分级。
- 问题 3：对葡萄和葡萄酒理化指标做主成分分析，再建立主成分回归关系，解释两组理化指标之间的联系。
- 问题 4：把感官质量、葡萄理化指标、葡萄酒理化指标统一转为秩和排序，通过相关性和变权分析判断能否用理化指标评价质量。

**高分信号：**
- 没有直接把原始评分、理化指标和芳香物质硬加权，而是统一转换为“秩和排序”，解决量纲和数量级差异。
- 问题 1 先做显著性检验，再讨论可信度，避免直接凭均值大小判断哪组评酒员更可靠。
- 评价类主线完整：指标筛选、排序转换、综合评价、分级、显著性或相关性检验都有落点。
- 对问题 2 的分级结果给出等级、样本编号和秩和区间，结果可直接回应“对酿酒葡萄进行分级”。
- 对问题 3 不只报告 PCA 结果，还用回归方程和显著性检验解释葡萄与葡萄酒理化指标之间的关系。

**失分风险：**
- 部分方法依赖 SPSS / Matlab 输出，若论文不说明数据处理细节和参数口径，可复现性会被扣分。
- TOPSIS 采用单一理想点接近度，若不解释理想点选择依据，容易被质疑代表性。
- 排序转换牺牲了原始数值差异，适合评价和分级，但不宜过度解释为精确质量差距。

**可回灌规则：**
- 评价类高分不等于“算权重 + 排名”，必须补齐指标筛选、正向化/标准化、排序或得分解释、显著性/稳定性检验。
- 多来源、多量纲指标可以先统一到秩次、标准分或接近度空间，再做综合评价。
- 判断评价者、专家组或方案可信度时，应优先比较组内一致性、与综合排序偏差或非参数检验结果，而不是只比均值。

**对应评分边界：** 90 分边界。理由：主线清楚、评价闭环完整、统计检验较充分；若复现细节和理想点依据再加厚，可作为评价类 95 分参考。

### 6. 2016 国赛 C 题：电池剩余放电时间预测

**来源文件：** `outputs/extracted_pdf_text/2016国赛国一C题优秀论文-电池剩余放电时间预测.txt`  
**材料类型：** 国赛一等奖优秀论文
