# outputs/visualization_strategy_library.md

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 用于把图表从“装饰品”升级成“结论表达工具”，沉淀不同图表适用场景、图后解释模板与常见踩坑。

---

## 一、总原则

1. 图表的任务是帮结论说话，不是替代结论。
2. 每张图至少要回答一个问题：
   - 趋势是什么？
   - 差异在哪里？
   - 结构如何？
   - 方案为何更优？
   - 结果是否稳定？
3. 同一信息不要重复堆图。
4. 图后最好固定补一句“这张图说明了什么”。

---

## 二、图表策略表

| 图表类型 | 最适合表达 | 常见场景 | 图后应补什么 |
|---|---|---|---|
| 折线图 | 趋势、阶段变化、拐点 | 预测、时序、演化 | 趋势、关键阶段、可能原因 |
| 柱状图 / 条形图 | 对比差异 | 排名、对象比较、方案对照 | 谁更高、差多少、优在哪里 |
| 雷达图 | 多指标轮廓 | 评价类多维比较 | 哪些维度突出、哪些短板明显 |
| 热力图 | 强弱结构、相关性 | 变量关系、时空强度 | 哪些区域/变量更突出 |
| 箱线图 | 分布与异常值 | 波动、稳定性、样本差异 | 波动范围、极端值含义 |
| 散点图 | 关系、聚类边界 | 回归、聚类、影响因素 | 是否存在线性/分层结构 |
| 混淆矩阵 | 分类误判结构 | 分类、预警识别 | 哪类最易混、误差在哪 |
| 收敛曲线 | 求解过程 | GA / PSO / ACO | 收敛速度、是否稳定 |
| 流程图 | 模型结构与职责 | 链式建模、组合模型 | 各模块职责和衔接 |
| 地图 / 空间图 | 空间差异 | 区域分布、时空演化 | 高低值区域与机制解释 |

## 三、按用途选图

### 1. 想表达趋势
- 首选：折线图
- 适用：预测、机理演化、阶段变化
- 图后句：
  - “由图可见，变量在【阶段】呈现【趋势】，其中【节点】变化最明显，说明【原因】。”

### 2. 想表达对象差异
- 首选：柱状图 / 条形图
- 适用：排序、方案比较、指标对照
- 图后句：
  - “由对比结果可见，【对象 A】在【指标】上明显优于【对象 B】，说明【解释】。”

### 3. 想表达多指标轮廓
- 首选：雷达图
- 适用：评价题多维画像
- 图后句：
  - “雷达图表明【对象】在【维度】上优势明显，但在【维度】仍存在短板。”

### 4. 想表达结构和相关性
- 首选：热力图
- 适用：相关矩阵、权重结构、时空热度
- 图后句：
  - “图中颜色差异表明【变量/区域】之间存在明显强弱分层，其中【位置】最值得关注。”

### 5. 想表达稳定性
- 首选：箱线图 / 情景对比图 / 收敛曲线
- 适用：灵敏度分析、智能算法稳定性
- 图后句：
  - “在不同扰动/不同运行条件下，结果波动范围较小，说明模型具有较好稳定性。”

### 6. 想表达链式结构
- 首选：流程图
- 适用：C 题、组合模型、链式建模
- 图后句：
  - “该图用于说明前一层输出如何进入后一层模型，而非重复正文步骤。”

## 四、不同阶段最该放什么图

### 1. 审题 / 分析阶段
- 题目结构图
- 指标体系图
- 数据字段说明图

### 2. 建模阶段
- 模型流程图
- 变量关系图
- 约束结构图

### 3. 结果阶段
- 关键趋势图
- 方案对比图
- 排名或分类结果图

### 4. 检验阶段
- 残差图
- 灵敏度扰动图
- 情景对比图
- 收敛图

### 5. 答辩阶段
- 一张总流程图
- 一张关键结果图
- 一张检验支撑图

## 五、图表高分策略

1. 一张图只传达一个主结论。
2. 图和表要分工：
   - 图负责看趋势和结构
   - 表负责看精确数值
3. 高分图表更强调：
   - 比较
   - 结构
   - 决策含义
4. 图标题尽量写成“对象 + 指标 + 时间/场景”，不要只写“结果图”。

---

## 六、来自样本路线的图表打法

### 1. 评价题
- **优先留图**：指标雷达图 + 排名柱状图 + 稳定性扰动图
- **原因**：能同时交代“谁更优、优在哪里、排序稳不稳”
- **图后句**：
  - “雷达图表明最优对象在【维度】上优势明显，而排名扰动结果说明该结论不依赖单一权重设定。”

### 2. 预测题
- **优先留图**：历史—预测折线图 + 误差对比图 + 关键阶段放大图
- **原因**：能同时交代趋势、预测精度和拐点变化
- **图后句**：
  - “由预测曲线可见，模型较好刻画了促销期需求峰值变化，并为后续库存准备提供了量化依据。”

### 3. 优化题
- **优先留图**：方案结构图 + 基准对照图 + 情景分析图
- **原因**：优化题最重要的不是收敛过程，而是方案结构和改进幅度
- **图后句**：
  - “与基准方案相比，新方案在【指标】上改善更明显，且在不同情景下保持相近结构，说明其可执行性更强。”

### 4. 链式题
- **优先留图**：一张总流程图 + 一张中间层结果图 + 一张最终方案图
- **原因**：这样最容易把“识别/预测 → 决策”闭环讲清楚
- **图后句**：
  - “流程图展示了中间层结果如何进入方案层，避免论文出现前后各写各的断链问题。”

---

## 七、常见低分问题

- 图很多但正文不解释
- 图标题过于空泛
- 坐标轴、单位、图例不完整
- 同一结论重复画多张图
- 只画炫图，不支撑核心结论
- 链式建模没有一张结构图说明模块衔接

---

## 八、最稳妥的图后补句

- “该图从可视化角度印证了前文结论。”
- “图表的主要作用是辅助说明结论，最终判断仍以模型结果与现实解释为依据。”
- “由图可见……这说明……”
- “进一步比较可知……因此建议……”
