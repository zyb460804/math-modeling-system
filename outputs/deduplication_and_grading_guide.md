# 资料去重与分级指南

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 系统同步说明：本文件已纳入根目录统一生产系统。调用时默认遵循：任务路由 → 知识更新/资料入库 → 数据理解 → 审题选模 → 代码/论文/图表/表格生产 → 最终质量门 → 答辩/提交模板 → 经验回灌。涉及字段、参数或附件时，先对齐 `outputs/data_cleaning_standards.md`；涉及提交、答辩或可复现判断时，先检查 `outputs/final_quality_gate.md`；缺真实数据或运行结果时，统一标为【待补】，不得编造。

## 用途

用于把根目录与后续新增材料中的重复资料、旧版资料和高价值资料分清楚，避免比赛时出现“资料很多但不知道用哪个”的问题。

## 基本原则

1. 不直接删除原始资料，先登记、分级、标注推荐版本。
2. 每类任务只保留一个默认推荐入口。
3. 根目录 `outputs/`、`prompts/`、`.claude/skills/` 构成唯一生产系统主入口。
4. 代码资产优先整理 Python，高频算法优先于冷门算法。
5. 个案作品只沉淀可泛化经验，不直接覆盖通用规则。

## 分级标准

| 等级 | 定义 | 处理方式 | 典型资产 |
|---|---|---|---|
| S | 比赛中可直接调用，结构清楚，风险低 | 进入 `outputs/asset_registry.md` 默认推荐 | 路由器、方法匹配、终检清单、论文模板 |
| A | 稍作改写即可用，内容可靠但需适配题目 | 保留并标注适用场景 | 算法模板、图示模板、优秀论文结构 |
| B | 可参考，但不宜作为默认入口 | 归档到参考资料或原始资料 | 扫描版讲义、旧案例、泛用素材 |
| C | 重复、旧版、风险高或临场不建议使用 | 标注旧版/备选，不进入默认路径 | 多份同名模板、未经验证代码、过度复杂模型 |

## 去重判断规则

| 判断维度 | 说明 | 推荐保留版本 |
|---|---|---|
| 内容完整度 | 是否包含输入、方法、输出、风险 | 完整链条优先 |
| 生产可用性 | 是否能直接服务论文、代码、图表或提交 | 可直接产出优先 |
| 版本新旧 | 是否与当前 2025/2026 规则和系统一致 | 新版优先 |
| 路径位置 | 是否在根目录 `outputs/`/`prompts/` 体系内 | 体系内优先 |
| 可复现性 | 代码是否有入口、依赖、样例和输出 | 可运行优先 |
| 表达质量 | 是否能直接转化为论文语言 | 高分表达优先 |
| 风险程度 | 是否容易误导选模或堆复杂模型 | 风险低优先 |

## 推荐目录职责

| 目录 | 定位 | 处理建议 |
|---|---|---|
| `outputs/` | 规则库、模板库、索引库（主生产系统） | 所有新规则、新索引优先写入此处 |
| `prompts/` | 工作流提示词 | 每个提示词只负责一个任务 |
| `.claude/skills/` | Skill 自动化流水线 | 正式赛题优先走轨道 A |
| `deliverables/` | 成品模板和提交资产 | 放可直接套用或继续打磨的产物 |
| `resources/` | 原始资料归档区（按类别编号） | 不作为默认生产入口 |
| `resources/_archive/` | 历史归档（含 `math-model-producer_old/`） | 不再更新，仅查阅 |

## 高频重复资产处理建议

### 1. 提示词重复

- 保留根目录 `prompts/` 作为主提示词目录。
- 每个提示词只负责一个任务：扫描、抽卡、建规则、审稿、写论文、代码、表格、图示、汇报、提交。

### 2. 代码重复

- 同一算法同时有“14 种必备算法”和“50 多种算法”版本时：
  1. 优先选更清晰、更短、更容易改造的 Python 版本。
  2. Matlab 版本保留为参考，不作为默认生成目标。
  3. 若两个 Python 版本功能重叠，保留能解释输入输出和结果的版本作为推荐版。
- 高频优先级：TOPSIS/熵权法、PCA、随机森林/XGBoost、ARIMA/灰色预测、线性/整数规划、GA/PSO、蒙特卡洛。

### 3. 论文模板重复

- 保留 `deliverables/papers/数学建模论文模板.md` 作为主模板。
- Word 模板作为格式参考，不直接替代内容结构。
- 摘要、结果分析、结论等表达优先从 `outputs/writing_templates.md` 调用。

### 4. 图表资料重复

- 保留 `outputs/figure_templates.md` 作为图示结构入口。
- 原始图表代码作为代码资产，不直接作为论文图表方案。
- 每张图必须绑定一个表达任务：路线、结构、诊断、对比、灵敏度或结果解释。

## 去重记录模板

| 资源主题 | 推荐版本 | 备选版本 | 旧版/重复版本 | 等级 | 原因 | 下一步 |
|---|---|---|---|---|---|---|
| 待补 | 待补 | 待补 | 待补 | S/A/B/C | 待补 | 保留/归档/改造/跳过 |

## 执行顺序

1. 先更新 `outputs/file_map.md`，确认所有新增资料已登记。
2. 再按本指南给资源分级。
3. 把 S/A 级资产写入 `outputs/asset_registry.md`。
4. 对代码资产另按 `outputs/python_algorithm_template_standard.md` 判断是否值得工程化。
5. 不确定是否删除时，默认保留并标注为 B/C 级参考资产。
