# outputs/code_template_playbook.md

> **v2.0 标准化 | 2026-05-31** | 统一索引见 `outputs/INDEX.md`

> 用于把零散代码模板整理成“适用场景 / 输入输出 / 参数说明 / 论文怎么写 / 常见报错 / 答辩怎么讲”的代码说明书。

---

## 一、总原则

1. 代码模板的作用是加速起步，不是替代建模判断。
2. 生成或改代码前，先查 `outputs/code_asset_index.md`，确认已有 Python / Matlab 模板属于评价、预测、优化、预处理、分类聚类还是机理仿真。
3. 每个模板至少要回答六件事：
   - 什么时候用
   - 输入是什么
   - 输出是什么
   - 关键参数是什么
   - 论文里怎么写
   - 最容易出什么错
4. 能用基础模板闭环时，不要为了显得高级强行升级。

## 二、模板说明书

### 1. TOPSIS
- **适用场景**：多指标排序、综合优选
- **输入**：指标矩阵、指标方向、可选权重
- **输出**：各对象贴近度与排序结果
- **关键参数/前提**：必须先统一正负向并完成标准化
- **论文怎么写**：
  - “在完成指标正向化与无量纲化后，采用 TOPSIS 计算各方案到正负理想解的距离，并据此得到综合排序。”
- **答辩怎么讲**：
  - “TOPSIS 负责排序，不负责赋权；如果权重需要说明，还要配合 AHP 或熵权法。”
- **常见错误**：
  - 原始量纲直接算距离
  - 负向指标未转正
  - 排序后不解释差异来源

### 2. 熵权法
- **适用场景**：客观赋权
- **输入**：标准化后的指标矩阵
- **输出**：各指标权重
- **关键参数/前提**：数据列应有区分度
- **论文怎么写**：
  - “考虑到指标具有客观观测数据，本文采用熵权法确定权重，以减少主观赋权偏差。”
- **答辩怎么讲**：
  - “熵权法只负责赋权，通常需要和 TOPSIS、模糊综合评价等评价模型联用。”
- **常见错误**：
  - 某列全相同仍强行赋权
  - 只给权重，不接最终评价

### 3. PCA
- **适用场景**：高维特征压缩、指数构建、预处理
- **输入**：标准化后的多维特征
- **输出**：主成分、解释方差比、降维结果
- **关键参数/前提**：要说明保留主成分数的依据
- **论文怎么写**：
  - “考虑到原始特征维度较高且相关性较强，本文采用 PCA 提取主成分，以降低冗余并保留主要信息。”
- **答辩怎么讲**：
  - “PCA 是预处理工具，不是最终预测、分类或评价结论。”
- **常见错误**：
  - 不标准化直接做 PCA
  - 不解释累计解释方差
  - 把 PCA 当最终模型

### 4. 随机森林回归/分类
- **适用场景**：非线性预测、分类基线、特征重要性分析
- **输入**：特征矩阵、标签/目标变量
- **输出**：预测结果、分类结果、特征重要性
- **关键参数/前提**：训练集/测试集划分、树数、深度等超参数
- **论文怎么写**：
  - “考虑到变量关系可能具有非线性特征，本文采用随机森林建立基线模型，并通过测试集指标评估其效果。”
- **答辩怎么讲**：
  - “随机森林既给出预测能力，也提供变量重要性，便于解释关键因素。”
- **常见错误**：
  - 全量训练不留测试集
  - 只报精度不解释变量重要性

### 5. ARIMA / SARIMA
- **适用场景**：线性时序、带趋势或季节性的序列预测
- **输入**：时间序列数据
- **输出**：未来预测值、拟合结果
- **关键参数/前提**：平稳性、自相关结构、季节性
- **论文怎么写**：
  - “在识别序列平稳性与相关结构后，本文采用 ARIMA / SARIMA 模型进行预测，并通过误差指标与残差检验验证其有效性。”
- **答辩怎么讲**：
  - “该模型适合提取线性时序结构；若残差仍有明显非线性，再考虑组合模型。”
- **常见错误**：
  - 不做残差检验
  - 不解释为什么该序列适合 ARIMA

### 6. GM(1,1)
- **适用场景**：小样本趋势预测
- **输入**：短序列观测值
- **输出**：预测值、精度等级判断
- **关键参数/前提**：序列需有一定单调趋势
- **论文怎么写**：
  - “考虑到样本量较小且整体趋势较稳定，本文采用灰色预测 GM(1,1) 模型进行预测。”
- **答辩怎么讲**：
  - “GM(1,1) 更适合小样本趋势提取，不适合高噪声复杂波动序列。”
- **常见错误**：
  - 不报后验差比 C 和小误差概率 P
  - 序列明显高波动仍硬用

### 7. Prophet
- **适用场景**：存在趋势和季节结构的中短期序列
- **输入**：时间字段、观测值
- **输出**：趋势项、季节项、预测结果
- **关键参数/前提**：要先判断是否存在可解释的趋势/季节性
- **论文怎么写**：
  - “考虑到序列同时具有长期趋势和周期波动特征，本文采用 Prophet 模型进行建模与预测。”
- **答辩怎么讲**：
  - “Prophet 更像结构清晰的预测基线，不应替代全部时序诊断。”
- **常见错误**：
  - 只放预测图，不报误差

### 8. 整数规划 / 0-1 规划
- **适用场景**：选址、排班、指派、是否启用、固定费用、互斥逻辑
- **输入**：决策变量定义、目标函数、约束条件
- **输出**：离散最优方案
- **关键参数/前提**：变量必须有明确离散业务含义
- **论文怎么写**：
  - “考虑到决策变量本质上为 0-1 / 整数选择，本文建立整数规划模型描述资源配置与策略选择过程。”
- **答辩怎么讲**：
  - “0-1 变量刻画了选或不选、开或不开这类现实动作，大 M 用于表达启停、互斥或固定费用触发逻辑。”
- **常见错误**：
  - 用了 0-1 变量却不解释现实含义
  - 大 M 取值随意且不说明依据

### 9. PSO
- **适用场景**：连续变量、非凸优化、参数寻优
- **输入**：目标函数、变量边界、算法参数
- **输出**：近优解、收敛过程
- **关键参数/前提**：惯性权重、学习因子、粒子数、迭代次数
- **论文怎么写**：
  - “考虑到目标函数存在多峰或非凸特征，本文采用粒子群算法搜索近优解。”
- **答辩怎么讲**：
  - “PSO 适合连续变量近优搜索，不适合默认处理离散 0-1 决策。”
- **常见错误**：
  - 离散问题直接套 PSO
  - 不做多次运行稳定性说明

### 10. 遗传算法
- **适用场景**：离散组合优化、路径、排班、复杂搜索
- **输入**：编码方式、适应度函数、约束规则
- **输出**：近优方案
- **关键参数/前提**：编码设计、交叉率、变异率、种群规模
- **论文怎么写**：
  - “考虑到问题搜索空间庞大且具有离散特征，本文采用遗传算法进行全局搜索。”
- **答辩怎么讲**：
  - “遗传算法的关键不只是算法名，而是编码方式与适应度设计是否贴题。”
- **常见错误**：
  - 编码与实际变量脱节
  - 只给收敛图不解释方案结构

### 11. 蚁群算法
- **适用场景**：路径规划、巡回路线、网络搜索
- **输入**：节点边权、启发函数、信息素参数
- **输出**：较优路径
- **关键参数/前提**：问题必须已抽象为图
- **论文怎么写**：
  - “针对路径组合爆炸问题，本文采用蚁群算法对候选路径进行迭代搜索。”
- **答辩怎么讲**：
  - “蚁群算法适合路径类近优搜索，但前提是边权定义和图结构都清楚。”
- **常见错误**：
  - 还没图论化就上蚁群
  - 不解释边权的现实意义

### 12. Logistic 微分方程
- **适用场景**：增长、传播、饱和、自限系统
- **输入**：初值、增长率、容量上限
- **输出**：演化轨迹、稳定状态
- **关键参数/前提**：系统必须存在饱和或自限机制
- **论文怎么写**：
  - “根据系统存在先快后缓并趋于稳定的演化特征，本文建立 Logistic 微分方程进行刻画。”
- **答辩怎么讲**：
  - “关键不是方程本身，而是增长率与容量上限的现实含义。”
- **常见错误**：
  - 只会写方程，不解释参数

### 13. LSTM / GRU
- **适用场景**：大样本、长依赖、明显非线性时序
- **输入**：序列样本、训练参数
- **输出**：预测结果、测试误差
- **关键参数/前提**：样本规模、学习率、正则化、Dropout、梯度裁剪等稳定性控制
- **论文怎么写**：
  - “考虑到序列具有较强非线性和长时依赖特征，本文采用 LSTM 建模，并通过训练稳定性控制保证结果可信。”
- **答辩怎么讲**：
  - “若不用稳定性控制与测试集评估，深度学习结果很容易被质疑只是碰巧跑通。”
- **常见错误**：
  - 小样本硬上深度学习
  - 只放曲线，不解释训练控制

### 14. XGBoost
- **适用场景**：高维特征预测、非线性回归、销量/价格/需求类预测
- **输入**：特征矩阵、目标变量、训练集/测试集
- **输出**：预测值、测试集指标、特征重要性
- **关键参数/前提**：学习率、树深、树数；必须保留测试集或交叉验证
- **论文怎么写**：
  - “考虑到特征维度较高且变量关系具有明显非线性，本文采用 XGBoost 建立预测模型，并结合测试集指标评估泛化效果。”
- **答辩怎么讲**：
  - “XGBoost 的优势不只是精度，还在于能输出特征重要性，便于解释销量变化的关键驱动因素。”
- **常见错误**：
  - 只报 R² 或误差，不解释重要特征
  - 调参后不和基线模型比较

### 15. LightGBM
- **适用场景**：中大样本分类/预测、特征较多、需要较快训练速度的任务
- **输入**：特征矩阵、标签/目标变量
- **输出**：分类结果或预测结果、重要性排序
- **关键参数/前提**：目标函数、树深、叶子数、训练集/测试集划分
- **论文怎么写**：
  - “考虑到样本量较大且特征维度较多，本文采用 LightGBM 建立分类/预测基线模型，并通过测试集指标验证效果。”
- **答辩怎么讲**：
  - “LightGBM 适合做高效梯度提升基线，但若题目强调机理解释，仍需补充变量含义分析。”
- **常见错误**：
  - 只报准确率，不分析误判结构或关键特征
  - 把训练快误写成模型一定更优

### 16. NSGA-II
- **适用场景**：多目标优化、成本—效率权衡、Pareto 前沿分析
- **输入**：多个目标函数、变量范围、种群参数
- **输出**：Pareto 最优解集、不同目标间的折中方案
- **关键参数/前提**：非支配排序、拥挤度、种群规模、迭代次数
- **论文怎么写**：
  - “针对多个目标难以同时最优的问题，本文采用 NSGA-II 搜索 Pareto 解集，并据此分析不同目标之间的权衡关系。”
- **答辩怎么讲**：
  - “NSGA-II 的价值不在于给出唯一答案，而在于把多种可行折中方案同时呈现出来，便于按实际偏好选取。”
- **常见错误**：
  - 只放 Pareto 图，不解释如何从解集中选最终方案
  - 多目标本可加权求解，却没有说明为何要上 NSGA-II

## 三、模板选择顺序

1. 先看题型。
2. 再查 `outputs/code_asset_index.md` 是否已有同题型、同算法或同数据结构的可复用代码。
3. 再看数据规模与变量类型。
4. 再看是否需要解释性。
5. 最后决定是否升级到组合模型或复杂模型。

---

## 四、最稳妥的赛中用法

- 先选一个基础模板打底。
- 如果短板很明确，再补一个改进模板。
- 若 `outputs/code_asset_index.md` 中已有相近代码，优先改输入、字段名、参数和输出表，不要重写整套算法。
- 使用现成代码时必须补齐真实数据入口、随机种子或参数设置、运行结果保存路径和论文中对应表图位置。
- 写论文时同步把“模板步骤”翻译成“模型建立 + 算法流程 + 检验 + 结果解释”。
