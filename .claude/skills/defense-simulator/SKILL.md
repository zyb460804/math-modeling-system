# Defense Simulator — 答辩模拟器

> **此 skill 是 `/defense` 统一入口的内部调度工具。** 用户说"模拟答辩""答辩练习"等均由 `/defense` 统一接收后分派。本 skill 保留独立触发词仅用于向后兼容。

模拟数学建模答辩场景，根据论文内容生成评委问题和追问链。

## 触发词

`模拟答辩` `答辩练习` `评委提问` `答辩模拟` `准备答辩`

## 工作流

### Step 1: 加载论文内容

读取当前论文相关文件：
- `paper_output/final_paper_source.md` — 论文源稿
- `paper_output/results/` — 模型结果
- `paper_output/figures/` — 图表
- `outputs/defense_qa_bank.md` — 题库
- `outputs/defense_followup_chains.md` — 追问链模板

### Step 2: 生成问题

按以下维度生成 10 个问题：

| 维度 | 数量 | 来源 |
|------|------|------|
| 模型选择理由 | 2 | 论文模型建立部分 |
| 数据处理细节 | 2 | 论文数据预处理部分 |
| 结果解释 | 2 | 论文结果分析部分 |
| 方法局限性 | 2 | 论文假设和讨论部分 |
| 创新点/亮点 | 1 | 论文摘要和结论 |
| 实际应用 | 1 | 论文推广建议 |

### Step 3: 追问链

每个问题附带 2-3 层追问：
- 第 1 层：基础问题（直接从论文能回答）
- 第 2 层：深入追问（需要理解原理）
- 第 3 层：压力追问（质疑假设/方法合理性）

### 输出格式

```markdown
## 答辩模拟

### 问题 1：[问题]
**预期回答要点**：[从论文提取]
**追问 1.1**：[更深入的问题]
**追问 1.2**：[质疑性问题]
**评分标准**：[满分/扣分点]

### 问题 2：...

### 模拟评分
| 维度 | 得分 | 满分 | 扣分原因 |
|------|------|------|----------|
| 模型理解 | | 20 | |
| 数据处理 | | 15 | |
| 结果分析 | | 20 | |
| 创新亮点 | | 15 | |
| 表达能力 | | 15 | |
| 应变能力 | | 15 | |

### 风险预警
- [论文中最容易被质疑的 3 个点]
```

## 约束

- 问题必须基于论文实际内容，不编造
- 追问链要有逻辑递进关系
- 评分标准对标 `outputs/scoring_rubric.md`
