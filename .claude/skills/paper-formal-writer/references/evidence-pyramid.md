# 建模证据金字塔

> 数学建模中的证据层次理论——如何在论文中构建有说服力的证据链。

---

## 一、证据层次金字塔

```
          ╱  ╲
         ╱ 第   ╲         定量验证 + 实际数据
        ╱  一   ╲         （最强证据）
       ╱  层     ╲
      ╱─────────────╲
     ╱    第二层     ╲       理论推导 + 仿真模拟

  ╱─────────────────────╲
 ╱      第四层           ╲    假设推演 + 定性分析
╱───────────────────────────╲
```

## 二、各层级详解

### Tier 1：定量验证 + 实际数据（最强证据）

**定义**：模型输出与真实数据直接比较，误差在可接受范围内。

**典型形式**：
- 预测值 vs 实际值的对比表
- 残差分析（残差图、Q-Q 图）
- 交叉验证结果（K-fold CV）
- 回溯验证（用历史数据训练，预测未来时间段）
- 误差指标：R²、RMSE、MAE、MAPE

**在论文中的写法**：
```
模型的R²为0.873，RMSE为12.4，表明模型解释了87.3%的数据变异。
残差分析显示残差呈随机分布（无显著模式），表明模型假设基本成立。
```

**说服力等级**：★★★★★（最高）

---

### Tier 2：数学推导 + 仿真模拟

**定义**：模型的数学推导合理，仿真结果符合预期模式。

**典型形式**：
- 公式推导过程的完整性
- 算法收敛性证明
- 仿真结果与理论预期的一致性
- Monte Carlo 模拟的统计特性
- Sobol' 灵敏度分析

**在论文中的写法**：
```
由式(5)推导可知，当 λ→0 时目标函数退化为标准最小二乘，
与理论预期一致。Monte Carlo 仿真（N=1000）结果显示，
最优解的95%置信区间为[123.4, 145.6]，标准差为8.7。
```

**说服力等级**：★★★★☆

---

### Tier 3：专家判断 + 经验公式

**定义**：模型参数取值有领域文献支持，或经专家判断校准。

**典型形式**：
- 参数值来自权威文献（如 IPCC、统计年鉴）
- 经验公式的适用条件验证
- 专家打分的合理性论证
- 与领域共识的一致性

**在论文中的写法**：
```
碳排放因子取2.46 kgCO₂/kg（IPCC, 2019），该值已被广泛
应用于碳足迹计算。人口自然增长率取0.0052/year
（中国统计年鉴2023），与近5年趋势一致。
```

**说服力等级**：★★★☆☆

---

### Tier 4：假设推演 + 定性分析（最弱证据）

**定义**：模型在极端条件下的行为符合逻辑预期。

**典型形式**：
- 极端场景测试（boundary case testing）
- 定性趋势分析
- 逻辑推理链
- 类比论证

**在论文中的写法**：
```
当客户数量趋近于无穷大时，模型的配送成本增长率低于
线性增长，符合规模效应的经济学预期。在极端测试中
（客户密度=0.01/km²），模型仍能给出合理解。
```

**说服力等级**：★★☆☆☆

## 三、在论文中构建证据链

好的数学模型论文不是罗列公式，而是构建一条逻辑证据链：

```
问题定义 → 模型选择理由（为什么这个模型？）
   ↓
模型建立（公式+推导，证据来自数学理论 — Tier 2）
   ↓
模型求解（算法+计算，证据来自仿真/优化 — Tier 2）
   ↓
结果分析（数据+对比，证据来自定量验证 — Tier 1）
   ↓
模型评价（优缺点+灵敏度，证据来自多角度检验 — Tier 1/2/3）
```

每一环都要回答"为什么"：

| 环节 | 必须回答的问题 | 证据层级 |
|------|--------------|---------|
| 模型选择 | 为什么这个模型适合这个问题？ | Tier 3（文献支撑） |
| 模型建立 | 为什么这个公式能描述该现象？ | Tier 2（数学推导） |
| 模型求解 | 为什么这个算法能找到最优解？ | Tier 2（收敛性） |
| 结果分析 | 为什么结果可信？与什么对比？ | Tier 1（定量验证） |
| 模型评价 | 为什么模型在多种条件下都稳定？ | Tier 1/2（灵敏度+MC） |

## 四、证据层级与检验方法对照

| 证据层级 | 对应的检验方法 | 推荐程度 |
|---------|-------------|---------|
| Tier 1 | 误差分析（R²/RMSE/MAE）、交叉验证、回溯验证 | ★★★★★ 必做 |
| Tier 1 | Monte Carlo 扰动法 | ★★★★ 强烈推荐 |
| Tier 2 | 局部灵敏度分析（±10%/±20%） | ★★★★★ 必做 |
| Tier 2 | 全局灵敏度分析（Sobol'） | ★★★★ 美赛强烈推荐 |
| Tier 2 | 假设验证（正态性/线性/独立性检验） | ★★★ 推荐 |
| Tier 3 | 参数溯源（文献出处） | ★★★★ 必做 |
| Tier 3 | 多方法对比 | ★★★ 推荐 |
| Tier 4 | 极端场景测试 | ★★ 可选 |

## 五、证据不足时的处理策略

当某个主张的证据层级较低时：

| 情况 | 处理策略 |
|------|---------|
| 只有 Tier 4 证据 | 弱化结论措辞：用「可能」「初步表明」替代「证明」「显示」 |
| 缺 Tier 1 证据 | 补做交叉验证或回溯验证，至少做到 Tier 2 |
| 参数无文献支撑 | 快速搜索 Google Scholar / 知网，找到至少一个来源 |
| 结论无法验证 | 考虑删除该主张，或标注为「有待进一步验证」 |
