# /defense — 统一答辩准备入口

> **核心原则**：同一意图 → 默认最深输出。"准备答辩""模拟答辩""答辩练习""评委提问"均拿到相同全量答辩准备包。

## 触发词（统一入口）

以下触发词**全部**路由到本 skill：`准备答辩` `模拟答辩` `答辩练习` `评委提问` `答辩模拟`

## 架构

```
用户说任何答辩相关触发词
        │
        ▼
  ┌─────────────────────────┐
  │  /defense（本 skill）     │
  │  统一入口                │
  └──────┬──────────────────┘
         │
         ├──► 阶段1: 答辩基础问答库（高频问题+标准回答+风险提示+稳妥口径）
         ├──► 阶段2: 追问链生成（每类问题3层追问+应答策略）
         ├──► 阶段3: 模拟评分（6维度答辩打分+扣分原因）
         ├──► 阶段4: 30-60秒短答模板（选模理由/替代方法/边界/创新短板）
         └──► 阶段5: 分题型答辩重点+风险回避话术
```

## 工作流

### Step 1: 加载论文内容

读取当前论文相关文件：
- `paper_output/final_paper_source.md` — 论文源稿
- `paper_output/results/` — 模型结果
- `paper_output/figures/` — 图表
- `outputs/defense_qa_bank.md` — 题库
- `outputs/defense_followup_chains.md` — 追问链模板
- `outputs/defense_opening_and_closing.md` — 开场与收尾

### Step 2: 生成答辩基础问答库

按以下维度生成完整的问答库：

| 题型维度 | 题数 | 覆盖内容 |
|---------|------|---------|
| 题目理解 | 2 | 题型本质、最终输出、子问题关系 |
| 模型选择理由 | 2 | 为什么选这个模型、为什么不选另一个常见模型 |
| 数据处理细节 | 2 | 数据来源、预处理、指标选择依据 |
| 模型求解与算法 | 2 | 算法参数、求解流程、可复现性 |
| 结果解释 | 2 | 结果含义、差异来源、现实落地 |
| 模型检验 | 2 | 误差/灵敏度/稳健性/基准对照证据 |
| 方法局限性 | 2 | 模型边界、不适用场景、改进方向 |
| 创新点/亮点 | 1 | 补了什么短板、为什么有效 |
| 实际应用 | 1 | 结果如何指导决策或实践 |

每个问题附带：标准回答 + 风险提示 + 稳妥口径

### Step 3: 生成追问链

对每类问题生成 3 层追问：

- **第 1 层（基础追问）**：从论文可直接回答的深入问题
- **第 2 层（原理追问）**：需要理解模型原理才能回答
- **第 3 层（压力追问）**：质疑假设/方法合理性，考察边界意识

### Step 4: 生成模拟评分

按 6 维度对答辩表现进行预估评分：

| 维度 | 满分 | 预判 | 扣分原因 |
|------|------|------|----------|
| 模型理解 | 20 | | |
| 数据处理 | 15 | | |
| 结果分析 | 20 | | |
| 创新亮点 | 15 | | |
| 表达能力 | 15 | | |
| 应变能力 | 15 | | |

评分标准对标 `outputs/scoring_rubric.md`。

### Step 5: 生成短答模板

为以下核心问题准备 30-60 秒短答：
1. "请用一句话介绍你们的论文"（题目+方法+结果+价值）
2. "为什么选这个模型？"（对比至少一个替代方案）
3. "结果为什么可信？"（检验证据）
4. "模型有什么局限？"（边界意识）
5. "创新点在哪里？"（补了什么短板）

### Step 6: 分题型答辩重点

按题型标注答辩时的必讲项和易失分项（见 rubric §8 分题型答辩重点）。

### Step 7: 风险预警

标注论文中最容易被评委质疑的 3-5 个点，每个点给出：
- 风险是什么
- 如果被问到怎么回答
- 如果不能完美回答，稳妥口径是什么

## 输出格式

```markdown
## 答辩准备包

### 一、10类高频问答（标准回答+风险+稳妥口径）

### 二、追问链（每类3层×10类=30条追问+应答策略）

### 三、模拟答辩评分表

### 四、30-60秒短答模板（5个核心问题）

### 五、分题型答辩重点清单

### 六、风险预警（3-5个最易被质疑点+应对方案）
```

- 问题必须基于论文实际内容，不编造
- 追问链要有逻辑递进关系
- 所有评分对标 `outputs/scoring_rubric.md`
