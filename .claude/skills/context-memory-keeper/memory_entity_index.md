# Memory Entity Index

> **用途：** 跨赛题积累的实体追踪索引。每次竞赛使用 MODEL/ALGORITHM/CODE 后在此记录。
> **借鉴：** GBrain 知识图谱实例化 + Karpathy 双向引用。
> **关联：** → `outputs/knowledge_graph.md`（图谱定义） | → `memoryskill.md`（当前活跃实体）

---

## 使用说明

1. **何时更新：** 选定模型/算法、生成代码、产出结果时
2. **格式：** 每个实体一行，标注：类型、名称、使用赛题、状态、关联文件
3. **双向引用：** 实体条目中用 `→` 指向关联文件，用 `←` 标注被谁引用
4. **查询方式：** 按实体类型或赛题过滤，快速找到历史经验

## 维护规则

1. **新增实体：** 每次竞赛选定模型/算法后立即记录
2. **更新状态：** 运行代码/产出结果后更新对应实体的状态列
3. **双向一致性：** 引用的文件路径必须存在，不存在时标注 `[已删除]`
4. **定期审查：** 赛季结束后统计复用频率，淘汰低频实体，强化高频实体
5. **与知识图谱同步：** 新增实体时检查 `outputs/knowledge_graph.md` 是否已有定义，没有则补充
