# 图表面板证据分层原则

> **来源**：从 `nature-figure` v5.0（已归档）抽取核心方法论，国赛适配。
> **用途**：多面板图表的"每面板一证据"原则，强化 `figure-contract-template.md`。
> **配合**：`figure-contract-template.md`（图表合同模板）+ `math-figure/render_check.py`（图表质量门禁）。

---

## 核心原则

> "每张图是一个视觉论证，不是孤立的好看图表。"

图表生成前，必须先建立 **figure contract**（核心结论→面板证据→原型分类→渲染规格）。

---

## Figure Contract 四步法

### Step 1: 核心结论（一句话）

这张图要证明什么？用一句话写下来：

```
✅ "灵敏度分析表明，模型对需求参数的敏感度远高于成本参数。"
✅ "三阶段优化的总成本比单阶段低 12.3%。"
❌ "展示优化结果。"（太模糊）
❌ "画一个柱状图。"（这不是结论）
```

**规则**：如果你不能用一句话说清这张图的结论，说明你还不知道为什么要画它。

### Step 2: 面板证据链（每个面板 = 一个独立证据）

多面板图中，**每个面板必须承载一个独立的证据**，支撑 Step 1 的结论。

| 面板数 | 适合场景 | 证据结构 |
|--------|---------|---------|
| 1 个 | 单一结论 + 单一证据 | 一图一结论 |
| 2-3 个 | 对比/分解（如：方法 A vs 方法 B） | 每面板一个条件 |
| 4-6 个 | 多维度证据（如：4 个参数的灵敏度） | 每面板一个维度 |

**禁止面板**：
- ❌ 与结论无关的面板（"顺便画的"）
- ❌ 重复信息的面板（两个面板说同一件事）
- ❌ 信息量太低的面板（只有 2 个数据点的柱状图）

### Step 3: 原型分类

按图的论证角色分类，决定布局：

| 原型 | 特征 | 布局建议 |
|------|------|---------|
| **定量网格** | 多子图展示同类结果（如各参数灵敏度） | 等大网格（2×2 / 2×3） |
| **示意+定量混合** | 左侧原理图 + 右侧结果图 | 非对称（左小右大 或 左图右数据） |
| **图像+定量板** | 俯视图/热力图 + 旁边放数值 | 左大图右小表 |
| **不对称混合** | 1 个主图 + 2-3 个辅助小图 | 突出主图（占 60% 面积） |

### Step 4: 渲染规格

| 参数 | 国赛标准 | 美赛标准 |
|------|---------|---------|
| DPI | ≥ 300（Word 嵌入） | ≥ 300（PDF 嵌入） |
| 尺寸 | 单栏 8cm / 双栏 17cm | 单栏 88mm / 双栏 180mm |
| 字号 | ≥ 8pt（坐标轴） / ≥ 10pt（图例） | ≥ 7pt（坐标轴） / ≥ 8pt（图例） |
| 格式 | PNG（Word）/ SVG（矢量） | PDF / SVG |
| 配色 | 白底 + 1-2 强调色 | 同左 |

## 国赛 vs 美赛图表差异

| 维度 | 国赛 | 美赛 |
|------|------|------|
| 后端 | Python（matplotlib/seaborn） | Python 或 R（二选一，不混用） |
| 风格 | 简洁学术，一图一结论 | 同左，可更精致 |
| 颜色 | 统一色系，红绿仅用于方向 | 同左 |
| 语言 | 中文标注 | 英文标注 |
| 导出 | PNG 优先（Word 嵌入） | PDF/SVG 优先（LaTeX 嵌入） |

## 常见面板证据设计模式

### 模式 1：对比证据（方法 A vs B）

```
┌─────────────┬─────────────┐
│  方法 A 结果  │  方法 B 结果  │
│  (子图 a)    │  (子图 b)    │
└─────────────┴─────────────┘
        结论标注在图下方：
        "方法 A 比方法 B 提升 X%"
```

### 模式 2：分解证据（多维度灵敏度）

```
┌────┬────┐
│参数1│参数2│
├────┼────┤
│参数3│参数4│
└────┴────┘
  每个子图：参数变化 vs 目标值变化
  结论：哪些参数敏感（曲线陡），哪些不敏感（曲线平）
```

### 模式 3：原理+结果证据

```
┌──────────┬──────────────────┐
│  原理图   │    结果图         │
│ (示意图)  │  (真实数据可视化)  │
│  占 30%   │    占 70%         │
└──────────┴──────────────────┘
  左图说"我们怎么做的"，右图说"效果如何"
```

## 颜色策略

### 统一色系原则

> "Prefer unified method families across all panels over maximal hue separation."

- 同一张图内，**同一类对象用同一颜色**（如所有"真实值"用蓝色，所有"预测值"用红色）
- **不要**为了好看而每条线用不同颜色（彩虹色）
- 红绿**仅**用于方向性信号（涨/跌、正/负、好/坏）

### 色盲友好

- 避免：红绿组合（最常见的色盲冲突）
- 推荐：蓝橙组合（色盲友好 + 黑白打印可区分）

## 自检清单

生成图表前，逐项确认：

- [ ] 能用一句话说出这张图的结论
- [ ] 每个面板承载一个独立证据
- [ ] 没有与结论无关的面板
- [ ] 没有重复信息的面板
- [ ] 配色统一（非彩虹色）
- [ ] 红绿仅用于方向性信号
- [ ] DPI ≥ 300
- [ ] 字号 ≥ 8pt
- [ ] 通过 `render_check.py`
