# 论文字数统计

## 触发词

`字数统计` `多少字了` `字数够了吗` `统计字数` `word count`

## 功能

1. **扫描论文**：从 `paper_output/` 中的 .md 文件读取正文
2. **分段统计**：按章节（摘要、问题分析、模型建立、求解、结论等）分别统计
3. **中英文分离**：分别统计中文字符数和英文单词数
4. **附加统计**：图表数量、公式数量、参考文献数量
5. **达标判断**：对标国赛 18000 字要求，给出差距提示

## 输出格式

```markdown
## 论文字数统计报告

### 总体统计
| 指标 | 数值 | 目标 | 状态 |
|------|------|------|------|
| 中文字数 | 12,345 | ≥15,000 | ⚠️ 差 2,655 字 |
| 英文单词 | 2,100 | - | ✅ |
| 图片数量 | 8 | ≥5 | ✅ |
| 表格数量 | 4 | ≥3 | ✅ |
| 公式数量 | 15 | ≥10 | ✅ |
| 参考文献 | 12 | ≥8 | ✅ |

### 各章节字数
| 章节 | 中文字数 | 英文词数 | 占比 |
|------|---------|---------|------|
| 摘要 | 450 | 120 | 3.2% |
| 问题分析 | 1,200 | 300 | 8.5% |
| 模型建立 | 3,500 | 800 | 25.0% |
| ...  | ... | ... | ... |

### 建议
1. 模型建立章节偏短，建议补充推导过程
2. 结论章节可扩展改进方向
```

## 使用方式

```
/word-counter           # 统计当前论文
/word-counter --watch   # 实时监控模式（每 30 秒刷新）
```

## 依赖

- Python 3.8+
- re（标准库）
