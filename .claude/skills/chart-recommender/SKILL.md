# Chart Recommender — 图表推荐器

> **此 skill 是 `/figure` 统一入口的内部调度工具。** 用户说"推荐图表""画什么图""可视化方案"等均由 `/figure` 统一接收后分派到本 skill。本 skill 保留独立触发词仅用于向后兼容。

根据题型、数据特征和展示目的，推荐最佳图表方案并生成代码。

## 触发词

以下触发词会先由 `/figure` 统一入口接收，然后分派到本 skill：
`推荐图表` `画什么图` `图表方案` `可视化方案` `选图`

## 工作流

### Step 1: 分析需求

从用户描述中提取：
- **题型**：评价 / 预测 / 优化 / 分类 / 聚类 / 图论 / 仿真
- **数据维度**：单变量 / 双变量 / 多变量 / 时序 / 网络
- **展示目的**：对比 / 分布 / 趋势 / 相关 / 组成 / 空间
- **输出场景**：论文正文 / 答辩 PPT / 探索性分析

### Step 2: 查询知识库

读取以下文件：
1. `outputs/visualization_strategy_library.md` — 可视化策略库
2. `outputs/figure_templates.md` — 图表模板
3. `outputs/chart_explanation_templates.md` — 图表说明模板

### Step 3: 输出推荐

```markdown
## 图表推荐

### 主图方案
- **图表类型**：[如：分组柱状图 + 误差棒]
- **适用场景**：[理由]
- **参考模板**：resources/06_图表教程/...

### 辅助图方案（1-2 个）
- **图表类型**：[如：热力图]
- **适用场景**：[理由]

### 代码模板
```python
# 完整可运行的 matplotlib 代码
```

### 图表说明模板
- [从 chart_explanation_templates.md 提取填空式说明]

### 导出建议
- 论文正文：PNG 300 DPI / SVG
- 答辩 PPT：PNG 150 DPI / 交互式 HTML
```

## 图表类型速查

| 题型 | 推荐主图 | 推荐辅图 |
|------|----------|----------|
| 评价 | 雷达图、柱状图 | 热力图、排名图 |
| 预测 | 拟合曲线+置信区间 | 残差图、误差分布 |
| 优化 | 收敛曲线、3D曲面 | 等高线、平行坐标 |
| 分类 | 混淆矩阵热力图 | ROC曲线、散点矩阵 |
| 聚类 | 聚类散点图(PCA降维) | 轮廓系数图 |
| 图论 | 网络拓扑图 | 最短路径高亮图 |
| 仿真 | 时间序列图 | 敏感性分析图 |
