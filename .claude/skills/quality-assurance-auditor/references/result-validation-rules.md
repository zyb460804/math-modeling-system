# 结果验证规则集

> **来源**：从 `result-validator`（已归档，原 user-invocable: false 自动触发）抽取硬编码规则。
> **用途**：模型结果数值合理性的具体检查规则，补充 `check_result_reasonableness.py`（配置驱动）。
> **配合**：`check_result_reasonableness.py`（主脚本）+ `check_numeric_sanity.py`（inf/nan/量级扫描）。

---

## 三层验证

### 1. 范围检查（Range Check）

模型输出的数值必须在物理/数学合理范围内：

| 量纲 | 合理范围 | 违反时的原因 |
|------|---------|------------|
| 概率值 | ∈ [0, 1] | softmax 未归一化 / sigmoid 溢出 |
| 百分比 | ∈ [0, 100] | 归一化基准错误 |
| 相关系数 | ∈ [-1, 1] | 计算公式错误（未除以标准差） |
| 方差/标准差 | ≥ 0 | 数值不稳定 / 数据全相同 |
| 距离 | ≥ 0 | 坐标系错误 / 公式错误 |
| 计数 | ≥ 0 且为整数 | 浮点累积误差 / 类型错误 |
| RMSE/MAE/MAPE | ≥ 0 | 计算错误 |
| R² | ≤ 1（可 < 0，模型比均值还差） | 过拟合 / 模型错误 |
| AUC | ∈ [0, 1] | 概率输出错误 |
| 角度 | ∈ [0°, 360°] 或 [-180°, 180°] | 弧度/角度混淆 |

### 2. 统计检验验证

| 检查项 | 规则 | 常见错误 |
|--------|------|---------|
| p 值格式 | ∈ [0, 1]，标注显著性水平 | p=0.000（应写 p<0.001） |
| 显著性标注 | `*p<0.05, **p<0.01, ***p<0.001` | 星号与数值不匹配 |
| 置信区间 | 下界 < 上界，包含点估计 | 上下界反了 / 不含点估计 |
| 样本量 | 与原始数据一致 | 训练/测试集划分后忘记更新 |
| 自由度 | = n - k（n 样本量, k 参数数） | 忘记减参数数 |

### 3. 一致性检查

| 检查项 | 规则 |
|--------|------|
| 论文数字 vs 代码结果 | 必须一致（`check_number_consistency.py`） |
| 论文数字 vs frozen_numbers.json | 必须一致（冻结后不可改） |
| 摘要数字 vs 正文数字 | 必须一致 |
| 图表数字 vs 表格数字 | 必须一致 |
| 子问题间数字 | 逻辑一致（如 Q1 的输出 = Q2 的输入） |

---

## 配置驱动 vs 硬编码

`check_result_reasonableness.py` 是**配置驱动**的（读 `paper_output/plan/qa_config.json`），需要用户为每道题配置合理范围。

本文档提供**硬编码规则集**（不依赖配置，永远适用），作为补充：

- 配置驱动：题目特定的合理范围（如"本题成本应 < 10000 元"）
- 硬编码规则：通用的数学/物理约束（如"概率 ∈ [0,1]"永远成立）

---

## 自动触发机制

result-validator 原设计为 `user-invocable: false`（自动触发）。现在整合后，自动触发逻辑：

```
model-code-and-result-generator 产出结果
        │
        ▼
check_numeric_sanity.py          ← inf/nan/量级扫描（通用）
        │
        ▼
check_result_reasonableness.py   ← 配置驱动范围检查（题目特定）
        │
        ▼
本文档规则集（内置）             ← 数学/物理硬约束（通用）
        │
        ▼
通过 → 进入证据门禁
```

## 常见结果错误模式

| 错误模式 | 症状 | 根因 |
|---------|------|------|
| 概率溢出 | p = 1.05 或 p = -0.03 | softmax 温度参数错误 |
| R² > 1 | R² = 1.15 | 计算公式用了训练集 R² 公式但套到测试集 |
| 负距离 | d = -3.2 | 距离公式开根号前为负（数值误差） |
| 置信区间不含点估计 | μ=5.0, CI=[6.0, 8.0] | 置信区间和点估计用了不同数据 |
| p = 0.000 | 直接写 0 | 应写 p < 0.001 |
| 方差为负 | σ² = -0.5 | 数值不稳定 / 浮点误差累积 |

## 与其他脚本的关系

| 脚本 | 检查内容 | 配置依赖 |
|------|---------|---------|
| `check_numeric_sanity.py` | inf/nan/量级（通用） | 无 |
| `check_result_reasonableness.py` | 题目特定范围 | 读 `qa_config.json` |
| 本文档规则集 | 数学/物理硬约束 | 无（永远适用） |
| `check_number_consistency.py` | 论文 vs 代码数字一致 | 读 `frozen_numbers.json` |

---

## 禁止行为

- ❌ 跳过范围检查直接写论文（概率 > 1 是低级错误）
- ❌ 把 R² > 1 当成"模型特别好"（其实是计算错误）
- ❌ p = 0.000 直接写（应写 p < 0.001）
- ❌ 置信区间不包含点估计（统计常识错误）
- ❌ 子问题间数字不一致（Q1 输出 ≠ Q2 输入）
