# 评价 + 决策问题 Playbook

## 匹配条件
- 特征词：信贷风险、信用评价、定价策略、补货决策、供应商选择、综合评估、多指标评价、最优决策、资源配置、风险量化、违约概率、利率定价
- 题目类型：C 题（大数据/经管类），偶尔出现在 B 题
- 数学本质：多指标综合评价 + 多目标规划 / 最优化决策

## 典型题目索引
- 2020 国赛 C 题：银行对中小微企业的信贷决策
- 2021 国赛 C 题：生产企业原材料的订购与运输
- 2023 国赛 C 题：蔬菜类商品的自动定价与补货决策

## 解题示例（一种可行路径）

### Step 1：数据预处理与指标体系构建

指标构建原则：科学性、全面性、可操作性、层次性

### Step 2：信贷风险 / 综合得分的量化

**路径 A -- Logistic 回归模型**（有标签数据）：
$$\ln\left(\frac{p_i}{1-p_i}\right) = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \cdots + \beta_m x_{mi}$$

**路径 B -- PCA + 熵权法 / TOPSIS**（无标签数据）

**路径 C -- BP 神经网络**（缺失标签的推广预测）

### Step 3：多目标决策模型

目标函数：
$$\begin{cases}
\max \sum_{i} [r_i - (1-p_i)] \cdot x_i & \text{（净收益最大化）} \\
\min \max_i \{(1-p_i) \cdot x_i\} & \text{（最大个体风险最小化）}
\end{cases}$$

### Step 4：缺失数据的补全与模型推广

- 欧氏距离匹配法
- BP 神经网络预测
- KNN / 随机森林

### Step 5：突发因素/情景调整

量化突发事件对不同类别的影响方向和程度，修正评价指标或约束参数。

## 关键陷阱
1. 指标冗余与共线性
2. 风险与收益的量纲不统一
3. 忽略客户流失率
4. 异常值未处理或过度处理
5. 缺失数据补全缺乏验证
