## 解题示例（一种可行路径）

### Step 1：几何建模 -- 建立位置/轨迹的数学表达

**极坐标系**（圆/螺旋编队）：
- 等距螺线（板凳龙）：$r(\theta) = \frac{p}{2\pi}\theta$

**运动轨迹积分**（弧长求极角）：
- 极坐标弧长微分：$dl = b\sqrt{1+\theta^2}\,d\theta$
- 已知速度 $v$ 和时间间隔 $\Delta t$，通过 $l = v\Delta t$ 反求 $\theta_2$

### Step 2：相对位置关系分类与定位模型构建

**三角定位模型**（正弦定理）：
由观测角度和已知坐标，求未知点坐标。

### Step 3：迭代逐步逼近算法

**弧长反求极角的逼近**：
```
theta = theta_initial, step = step0, step_min = 1e-10
while step >= step_min:
    theta = theta - step
    if F(theta) < F(theta_1) - v * delta_t:
        theta = theta + step
        step = step / 2
```

### Step 4：运动学链式递推

**位置递推**：利用板凳长度约束建立方程
**速度递推**：余弦定理 + 方向向量分解

### Step 5：碰撞检测与极值搜索

**碰撞定义**：板凳矩形的 4 个顶点落入另一板凳矩形范围即判定碰撞。

**极值搜索模式**：
- 设定螺距上界，初始步长 0.01 m
- 逐步减小螺距，每次检查全过程中是否碰撞
- 若碰撞则退回上一个螺距，减半步长继续逼近
