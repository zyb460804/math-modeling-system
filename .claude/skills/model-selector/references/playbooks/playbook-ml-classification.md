# ML 分类/聚类问题 -- 以古代玻璃文物分类为例

## 匹配条件

- **特征词**：分类、聚类、鉴别、判别、亚类划分、类型识别、成分分析、文物鉴定、模式识别
- **题目类型**：C 题（大数据与数据挖掘）
- **数学本质**：监督/无监督分类 + 成分数据分析（Compositional Data Analysis）

## 典型题目索引

- 2022 国赛 C 题：古代玻璃制品的成分分析与鉴别
- 2021 国赛 C 题：生产企业原材料的订购与运输
- 2020 国赛 C 题：中小微企业的信贷决策

## 解题示例（一种可行路径）

### Step 1: 数据预处理与探索性分析（EDA）

成分数据具有"定和约束"（各组分之和为 100%），标准预处理流水线：

1. **无效数据剔除**：各成分累加和超出 85%~105% 的行视为无效
2. **成分数据闭合化**：将有效数据重新归一化到和为 100%
3. **中心化对数比变换（clr）**：
   $$\text{clr}(x) = \left(\ln\frac{x_1}{g(x)}, \ln\frac{x_2}{g(x)}, \ldots, \ln\frac{x_n}{g(x)}\right)$$
   其中 $g(x) = (x_1 \cdot x_2 \cdots x_n)^{1/n}$ 为几何均值
4. **缺失值处理**：未检测到的成分补 0
5. **分类变量量化**：对纹饰、类型、颜色等标签进行数值编码

### Step 2: 分类变量相关性检验（卡方检验）

- 期望计数 <5 的单元格比例 >20%：使用 **Yates 校正卡方检验**
- 比例 <=20%：使用标准 **Pearson 卡方检验**

### Step 3: 描述统计与可视化

分组计算均值、标准差、偏度系数、峰度系数等统计量。辅助工具：箱线图。

### Step 4: 监督分类（核心建模）

**模型选择逻辑**：

| 模型 | 适用条件 | 本场景是否合适 |
|------|---------|--------------|
| LDA | 正态性假定、等协方差 | 成分数据经 clr 后可用，但假定强 |
| KNN | 小样本、局部决策 | 需调 K，解释性弱 |
| **决策树** | 无需分布假定、解释性强 | 数据量适中(58 个样本)，最优选择 |

### Step 5: 无监督聚类（亚类划分 + 交叉验证）

1. 先做 **R 型聚类**（变量聚类）筛选特征变量
2. 以 R 型聚类结果为基础进行 **Q 型聚类**（样本聚类）
3. 聚类结果用于**交叉验证**监督分类的结果
4. **扰动参数做敏感性分析**

### Step 6: 结果分析

- 灰色关联分析：遍历每种化学成分作为母序列
- 敏感性分析：扰动原始数据，观察聚类结果稳定性

## 关键陷阱

1. **直接对成分数据用欧氏距离做聚类**：必须经过 clr 变换
2. **不做卡方检验就建模**
3. **决策树过拟合**：样本量小时必须控制树的深度
4. **混淆监督学习与聚类**
5. **忽略"成分数据"的领域特殊性**
