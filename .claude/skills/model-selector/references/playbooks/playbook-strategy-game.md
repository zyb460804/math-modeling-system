# 策略/博弈/多阶段决策 Playbook

## 匹配条件
- 特征词：博弈论、纳什均衡、动态规划、最优策略、多阶段决策、穿越沙漠、资源分配、天气随机、挖矿、补充资源、多人博弈、混合策略、收益矩阵、理性人、零和博弈、非合作博弈、静态博弈、路径规划、状态转移
- 题目类型：B 题（运筹/策略类）
- 数学本质：图动态规划 + 统计分析 + 静态/动态博弈 + 随机模拟验证

## 典型题目索引

## 解题示例（一种可行路径）

### Step 1：游戏机制的数学化建模
- 地图的图论表示
- 地图简化定理
- 状态空间定义：s = (天数 i, 位置 j, 水量 k, 食物量 l)
- 无后效性验证

### Step 2：图动态规划模型的建立

**状态定义**：dp(i, j, k, l) = 第 i 天结束时，玩家在位置 j，拥有 k 箱水和 l 箱食物时，能拥有的最多金钱数

**5 种状态转移方程**：
1. 起点购买
2. 村庄购买
3. 停留
4. 挖矿
5. 移动

### Step 3：随机天气下的统计分析与规则提炼

**小规模问题**：枚举所有可能的天气序列，统计分析提炼规则
**大规模问题**：抽样统计，蒙特卡洛模拟验证

### Step 4：多人博弈的数学建模

**静态博弈分析**：
1. 找出每个玩家的几种较优"单人策略"作为候选
2. 构建博弈收益矩阵
3. 纯策略纳什均衡分析
4. 若无纯策略均衡，转向混合策略均衡

1. 地图不是全连通的
2. "沙暴天必须停留"的规则容易忽略
3. 挖矿当天不能挖
