# ML 回归/预测 + 实验设计 -- 以乙醇偶合制备 C4 烯烃为例

## 匹配条件

- **特征词**：回归、预测、优化、收率、选择性、转化率、催化剂、工艺条件、实验设计、因素分析、正交试验
- **题目类型**：B 题（工程与优化）/ C 题（数据挖掘）
- **数学本质**：非线性回归 + 方差分析（ANOVA）+ 约束优化 + 实验设计

## 典型题目索引

- 2021 国赛 B 题：乙醇偶合制备 C4 烯烃
- 2020 国赛 B 题：穿越沙漠
- 2018 国赛 B 题：智能 RGV 的动态调度策略

## 解题示例（一种可行路径）

### Step 1: 数据预处理 -- 插值补全缺失条件

**解决方案：三次样条插值**

$$S_i(x) = a_i + b_i(x-x_i) + c_i(x-x_i)^2 + d_i(x-x_i)^3$$

### Step 2: 问题一 -- 非线性回归建模（乙醇转化率 vs 温度）

**Logistic 模型推导**：

$$x(T) = \frac{x_m}{1 + \left(\frac{x_m}{x_0} - 1\right)e^{-rT}}$$

对 21 种催化剂组合分别拟合，得到各自的最大转化率 $x_m$ 和增长率 $r$。

### Step 3: 问题二 -- 双因素方差分析（ANOVA）

$$SS_T = SS_A + SS_B + SS_E$$

温度的影响力 > 催化剂组合的影响力。

### Step 4: 问题三 -- 约束优化模型

五元二次回归方程 + 逐步回归筛选显著项 + fmincon 求解约束非线性优化。

### Step 5: 问题四 -- 实验设计

从建模过程的"信息缺口"出发设计实验：
1. 细化搜索实验
2. 验证实验
3. 对比实验
4. 时间优化实验
5. 填补空白实验

### Step 6: 结果分析

- 因素重要性排序：温度 > Co 负载量 > HAP 质量 > 乙醇浓度 > Co/SiO2 质量
- 最优方案可行性验证

## 关键陷阱

1. **直接线性拟合乙醇转化率**：必须用 Logistic 或类似的有界增长模型
2. **插值方法与物理背景脱节**：三次样条是底线
3. **混淆"选择性"和"收率"**
4. **因素分析不完整就做优化**
5. **实验设计停留在"再多做一些实验"**
