# /review — 审论文

全文评分、问题拆解、修改优先级清单。

> **核心原则**：同一意图 → 默认最深输出。说"审论文""打分""严格打分"均拿到相同全量报告。

## 执行方式

**直接委托 `paper-reviewer` agent**（`.claude/agents/paper-reviewer.md`）执行完整评审。

本 skill 不再独立维护评审逻辑，`paper-reviewer` agent 是评审的唯一权威实现。

`paper-reviewer` agent 默认输出全量深度报告（9 个部分）：
- 总分与等级 + 7模块分项评分（含四档定位）
- 9质量信号评估
- 13要素逐项四档定位 + 锚点对比
- 扣分细则逐条检查
- 真实论文锚点对比（85/90/95分边界）
- P0/P1/P2修改清单 + 提分路径
- 可提交/可复现/可答辩红线核验
- 三句话总结

**唯一例外**：用户明确说"只要总分，不要分析"时，输出精简版（总分+一句话）。

## 输入

- 论文文件路径（.md / .txt / .docx）

## 输出

- `paper-reviewer` agent 生成的完整评审报告

## 系统同步说明

任务路由 → 知识更新/资料入库 → 单题开工 → 数据理解 → 审题选模 → 代码/论文/图表/表格生产 → 动态验收 → 最终质量门 → 提交/答辩 → 经验回灌。
