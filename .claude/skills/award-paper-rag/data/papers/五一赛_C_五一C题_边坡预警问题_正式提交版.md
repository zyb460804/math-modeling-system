# 五一C题_边坡预警问题_正式提交版

边坡多源监测数据融合与三段式形变预警模型


# 摘要

针对边坡监测数据中存在传感器偏移、噪声强、异常跳变、缺失值以及多源扰动耦合等问题，本文建立了从数据校正、阶段识别、异常检测、多源关联分析到分阶段预警的完整数学建模框架。对问题1，建立二次多项式回归校正模型，五折交叉验证 RMSE 为 2.6838±0.0235 mm，决定系数达到 0.999223。对问题2，采用 Savitzky-Golay 平滑和多尺度滑动窗口速度分析，识别出附件2中两个阶段转换节点分别为编号3346和编号7386，三阶段平均速度分别为0.1178、0.3408和2.3157 mm/h。对问题3，采用三次样条插值与Savitzky-Golay滤波完成缺失补齐和去噪，结合IQR法和孤立森林识别异常点，并通过随机森林和梯度提升模型分析多源变量贡献，结果显示深部位移对表面位移贡献最大。对问题4，建立基于阶段划分的梯度提升回归模型，完成实验集表面位移预测。对问题5，从六类候选变量中筛选出孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量五变量最优组合，并构建黄色、橙色、红色三级预警阈值，分别为4.7100、10.0440和12.8400 mm/h。本文模型兼具数据驱动能力与工程解释性，可为边坡灾害早期预警提供定量参考。

关键词：边坡预警；三段式形变；多源数据融合；异常检测；梯度提升回归；位移速度阈值


# 1 问题重述

边坡稳定性是水利工程、交通路网和露天矿山等工程领域中的核心安全问题。受降雨入渗、孔隙水压力变化、爆破施工、微震活动及地质结构差异等因素影响，边坡在失稳破坏前通常呈现缓慢匀速形变、加速形变和快速形变三个阶段。由于实际监测数据普遍存在噪声、异常跳变、传感器漂移和缺失值，若不能准确识别阶段转换节点并建立多源融合预警模型，将严重影响边坡灾害预警的准确性和时效性。

本文需要完成：数据A校正、三段式形变节点识别、多变量数据预处理与异常检测、含爆破扰动的分阶段位移预测，以及基于位移速度的分级预警机制构建。


# 2 问题分析

本题本质上是“数据质量修复—非平稳阶段识别—多变量关联建模—预测预警”的综合建模问题。问题1属于传感器校准问题，可采用回归映射描述A与B之间的系统偏移；问题2属于非平稳时序分段问题，应利用速度和加速度特征判断形变阶段；问题3强调缺失、噪声和多变量共同异常的处理；问题4中外界扰动对不同阶段的影响不同，适合采用分阶段建模；问题5需要通过变量组合比较寻找最优预测特征，并将预测结果转化为工程可用的预警阈值。


# 3 模型假设

附件中给出的基准振弦式位移计数据B可作为问题1中的真实参考数据。

采样间隔固定为10 min，编号与时间一一对应。

缺失数据主要由传感器短时故障或传输异常造成，缺失区间内真实监测量可由相邻时刻趋势连续近似。

噪声和工程扰动造成的瞬时跳变不会长期改变位移速度趋势，而真实阶段转换会引起速度统计特征持续变化。

同一阶段内表面位移与降雨、孔隙水压力、微震、深部位移、爆破扰动等变量之间存在稳定统计映射关系。

训练集与实验集在相同阶段下的表面位移演化规律一致。

# 5 问题1：光纤位移计数据校正模型


## 5.1 模型建立

附件1中数据A与数据B为同一边坡同一监测点的两组位移序列，其中B为基准数据，A受传感器零漂和安装偏差影响。设校正映射为：

B̂_t = f(A_t) + ε_t

考虑传感器偏移既可能包含常值偏差，也可能随位移幅值发生轻微非线性变化，建立二次多项式校正模型：

B̂_t = β₀ + β₁A_t + β₂A_t²


## 5.2 模型结果

综合精度和稳健性，本文采用二次多项式模型：

B̂_t = -0.348981 + 0.880390A_t + 8.3432×10⁻⁷A_t²

五折交叉验证RMSE分别为2.6497、2.6973、2.6628、2.6968、2.7123 mm，平均为2.6838±0.0235 mm，说明模型稳定性较好。

# 6 问题2：三段式形变阶段转换节点识别


## 6.1 模型建立

设表面位移序列为y_t。首先采用Savitzky-Golay滤波对原始序列进行平滑，再计算局部速度。为避免瞬时跳变误判为阶段转换，本文采用滑动窗口平均速度作为阶段识别依据。真实阶段转换的判据为：若连续多个窗口的平均速度显著高于前期基线速度且之后不回落，则判定为真实阶段转换；若只在少数点出现尖峰，随后速度恢复，则判定为噪声或工程扰动。

v_t = (ỹ_t - ỹ_{t-1}) / Δt,   Δt = 1/6 h


## 6.2 转换节点识别结果

随着边坡由缓慢匀速阶段进入快速形变阶段，平均位移速度由0.1178 mm/h增加到2.3157 mm/h，增幅接近20倍，符合滑坡失稳前三段式形变规律。

# 7 问题3：多变量数据预处理、异常检测与关联分析


## 7.1 缺失值补齐与去噪模型

本文采用三次样条插值补齐缺失值，并使用Savitzky-Golay滤波进行去噪。三次样条插值保证函数值、一阶导数和二阶导数连续，适合监测时序数据的平滑过渡；Savitzky-Golay滤波在局部窗口内用低阶多项式最小二乘拟合，能够在保留趋势形态的同时抑制高频噪声。


## 7.2 异常值检测模型

单变量异常检测采用IQR法与孤立森林相结合，二者检出异常取并集作为单变量异常点。共同异常点定义为同一时刻至少两个变量同时异常。

共识别出共同异常点456个，说明多源监测数据中存在一定比例的同步异常，可能与工程扰动、传感器故障或局部环境突变有关。


## 7.3 多因素关联分析

结果表明，深部位移是表面位移变化的首要解释变量，说明边坡内部剪切变形对表面形变具有直接控制作用；孔隙水压力与累计降雨量也具有较强贡献，反映降雨入渗通过改变孔隙水压力降低抗滑稳定性的物理机制。

# 9 问题5：变量组合选择与分级预警机制


## 9.1 最优变量组合模型

附件5包含表面位移、降雨量、孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量。题目要求从除表面位移外的六类变量中选取五类变量建立模型。本文枚举全部6种组合，采用梯度提升回归和五折交叉验证评价误差。

最优组合为孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量。该组合去掉降雨量后交叉验证R²最高，说明在附件5数据中，降雨影响可能已通过孔隙水压力和干湿入渗系数间接体现。


## 9.2 分阶段位移速度统计与预警阈值

阈值设定的合理性在于：位移速度是三段式形变阶段最直接的表征量；阈值基于数据分位数而非主观给定，具有统计依据；分级阈值由低到高递增，能够兼顾预警灵敏性和误报控制。

# 10 模型评价与推广


## 10.1 模型优点

模型覆盖传感器校正、阶段识别、数据预处理、异常检测、预测分析和预警阈值构建，形成完整边坡预警流程。

三段式形变识别以速度持续变化为核心，与边坡蠕变失稳机制一致。

通过滑动窗口、滤波和多变量共同异常判据，有效降低单点噪声和瞬时扰动带来的误判。

梯度提升和随机森林能够刻画多源因素对位移的非线性影响。

特征重要性和速度阈值均可转化为工程解释，便于实际预警应用。


## 10.2 模型不足与改进

模型仍存在一定不足：附件4和附件5中部分模型交叉验证效果受时序非平稳性影响，阶段间预测存在一定跳跃，且附件5变量组合模型R²不高，说明仅依靠当前六类变量难以完全解释长周期表面位移。后续可引入LSTM、GRU或Transformer等时序模型，结合贝叶斯变点检测和物理稳定性模型，并对预警阈值采用动态自适应更新机制。


# 11 结论

对附件1光纤位移计数据，二次多项式校正模型能够有效修正系统偏移，校正模型R²=0.999223，五折交叉验证RMSE为2.6838±0.0235 mm。

附件2三段式形变转换节点分别为编号3346和编号7386，对应三阶段平均速度为0.1178、0.3408和2.3157 mm/h。

附件3中深部位移对表面位移贡献最大，特征重要性为0.6476，孔隙水压力和累计降雨量也具有较强解释作用。

附件4基于阶段划分的梯度提升模型能够预测实验集表面位移，预测结果随阶段演进总体增大。

附件5最优五变量组合为孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量；黄色、橙色、红色三级预警阈值分别为4.7100、10.0440和12.8400 mm/h。

# 附录：核心算法流程

A.1 数据校正算法：读取附件1数据A与B；建立线性、二次和三次多项式回归模型；计算RMSE、MAE、R²和最大误差；采用五折交叉验证评价模型稳定性；使用最优模型输出校正后的A数据。

A.2 三段式形变识别算法：对位移序列进行Savitzky-Golay平滑；计算滑动窗口平均速度；根据前期速度均值和标准差确定基线；若速度在多个连续窗口中显著高于基线且不回落，则判为真实转换；输出两个转换节点并分别建立线性、二次和指数模型。

A.3 多变量预警算法：对缺失数据进行三次样条插值；对补齐数据进行平滑去噪；使用IQR法和孤立森林检测异常；使用机器学习模型评估多源因素贡献；以位移速度分位数建立三级预警阈值。
