# 五一C题_边坡预警问题_新版论文

基于鲁棒校正与多源融合的边坡变形阶段识别及预警研究


# 摘要

边坡失稳前通常伴随由缓慢蠕变到加速变形再到快速破坏的阶段性演化，但实际监测数据常受到传感器漂移、环境噪声、工程爆破、降雨入渗和设备缺测等因素影响。针对五一数学建模竞赛C题，本文重新构建了一套以“鲁棒数据修复—速度特征识别—分阶段多源融合—速度阈值预警”为主线的数学模型。首先，针对光纤位移计与振弦式位移计之间的系统偏差，建立二次多项式校正模型，并以五折交叉验证评价校正精度，得到校正模型决定系数为0.999223，平均交叉验证RMSE为2.6838 mm。其次，针对三段式形变识别，采用Savitzky-Golay平滑和滑动窗口速度比判据，将附件2位移序列划分为三个阶段，两个转换节点分别为编号3346和7386。再次，对多变量监测数据采用三次样条补缺、局部多项式滤波去噪、IQR与孤立森林联合异常检测，并进一步识别同一时刻多变量共同异常点。关联分析表明，深部位移和孔隙水压力对表面位移具有最强解释作用。随后，针对爆破扰动的阶段依赖性，建立分阶段梯度提升预测模型，对实验集表面位移进行补全。最后，基于附件5的候选变量组合比较，选取孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量构成最优五变量组合，并以表面位移速度为核心指标建立三级预警阈值：4.7100、10.0440和12.8400 mm/h。结果表明，本文模型能够较好兼顾数据异常鲁棒性、阶段演化解释性和工程预警可操作性。

关键词：边坡预警；鲁棒校正；阶段识别；多源融合；异常检测；位移速度


# 1 问题重述与建模目标

边坡监测系统通常由表面位移、深部位移、孔隙水压力、微震事件、降雨和爆破扰动等多源数据构成。题目要求基于五个附件完成从传感器数据校正到滑坡预警机制构建的全过程建模。与单纯预测位移不同，本题关键在于同时解决数据质量、阶段转换和多源扰动解释三个问题。

本文将五个问题统一为一个闭环：第一步修正监测源自身误差；第二步从位移速度演化中识别边坡阶段；第三步清洗多源监测数据并识别异常；第四步考虑阶段差异建立位移预测模型；第五步将预测模型转化为速度阈值预警规则。


# 2 总体技术路线

本文采用的总体技术路线为：传感器校正模型→位移序列平滑→速度窗口统计→阶段转换识别→多变量缺失补齐→异常点联合判别→变量贡献分析→分阶段预测→位移速度预警。该路线的核心特点是避免用单点突变判断危险状态，而是强调速度趋势的持续变化和多源监测指标之间的协同异常。

原始监测数据 → 鲁棒预处理 → 阶段识别 → 多源融合预测 → 分级预警


# 3 模型假设

振弦式位移计数据可作为问题1中的校正基准。

各附件数据采样间隔固定，编号可按10分钟间隔转化为时间。

短时缺失主要由设备或传输异常造成，可用相邻趋势进行插补。

真实阶段转换表现为速度统计特征持续改变，瞬时跳变不作为阶段转换依据。

同一变形阶段内，多源环境扰动与表面位移之间存在相对稳定的非线性关系。

实验集与训练集在相同阶段下具有可迁移的位移演化规律。

# 5 问题1：基于多项式映射的位移计校正


## 5.1 模型思路

数据A与数据B来源于同一监测点，因此二者主要差异来自仪器零漂、安装偏差和量程响应差异。若仅使用常数偏移修正，无法描述随位移增大而变化的比例误差；若采用过高阶模型，则可能过拟合局部异常。因此本文选择二次多项式作为主模型，同时与线性和三次模型进行比较。

B̂_t = β_0 + β_1 A_t + β_2 A_t^2

参数通过最小二乘法估计，并采用RMSE、MAE、最大绝对误差和R²评价校正效果。为避免只在训练样本上表现良好，本文进一步采用五折交叉验证检验泛化能力。


## 5.2 计算结果

三次模型RMSE略低，但提升幅度很小。二次模型形式简洁、解释性更强，故选为最终模型：

B̂_t = -0.348981 + 0.880390 A_t + 8.3432×10^-7 A_t^2

五折交叉验证平均RMSE为2.6838±0.0235 mm，说明模型对不同数据划分具有稳定校正能力。

# 6 问题2：基于速度持续性的三段式形变识别


## 6.1 阶段转换准则

边坡失稳过程中的阶段变化本质上体现为位移速度水平的持续抬升，而不是某个时刻的孤立突变。因此本文提出速度持续性准则：若滑动窗口平均速度连续高于前期基线并保持增长，则判定为真实阶段转换；若仅表现为局部尖峰且随后回落，则判定为噪声或工程扰动。

v_t = (ỹ_t - ỹ_{t-1}) / Δt,  Δt = 1/6 h

v̄_i = (ỹ_{i+w} - ỹ_i) / (wΔt)


## 6.2 阶段划分结果

三个阶段平均速度逐级升高，阶段3速度约为阶段1的19.7倍，说明边坡由缓慢调整进入明显失稳加速状态。

# 7 问题3：多源数据修复、异常识别与贡献分析


## 7.1 数据修复

附件3训练集存在约5%的缺失。本文采用三次样条插值补齐缺失值，再采用Savitzky-Golay滤波去除高频噪声。样条插值适用于连续监测量的平滑恢复，局部多项式滤波则可在保留趋势的同时抑制传感器噪声。


## 7.2 异常检测

单变量异常检测采用IQR规则与孤立森林联合判别。IQR规则对极端值敏感，孤立森林适合识别不符合整体分布结构的样本。二者取并集可提高异常点召回率。共同异常点定义为同一时刻至少两个变量同时异常。

最终识别出共同异常点456个，说明部分异常并非单一传感器孤立误差，而可能对应环境扰动或监测系统同步异常。


## 7.3 变量贡献

深部位移的重要性最高，说明内部剪切变形对表面位移具有主控作用；孔隙水压力相关性较高，说明降雨入渗导致的有效应力变化是边坡变形的重要诱因。梯度提升模型五折交叉验证R²为0.7613±0.0209，略优于随机森林。

# 8 问题4：考虑爆破扰动的分阶段预测


## 8.1 阶段划分与特征构造

附件4中爆破点距离和单段最大药量仅在爆破时刻出现，非爆破时刻为空。因此本文将空值填为0，并额外设置是否爆破变量，从而避免将无爆破误认为缺失观测。考虑降雨和孔压影响存在滞后性，进一步构造1、3、6步滞后变量和滑动均值变量。


## 8.2 分阶段模型与预测

实验集预测位移总体范围为0.486--16.824 mm，平均值为7.495 mm。预测结果随阶段推进整体增大，说明分阶段建模能够反映边坡变形演化方向。

# 9 问题5：变量筛选与速度阈值预警


## 9.1 最优五变量组合

问题5要求从降雨量、孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量中选择五类变量。本文枚举6种删一变量组合，并用梯度提升回归的五折交叉验证结果比较模型误差。

最优组合为孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量。去掉降雨量后效果最好，说明降雨影响在该数据中可能已通过孔隙水压力和干湿入渗系数间接体现。


## 9.2 分级预警阈值

该阈值体系以位移速度分位数为基础，兼顾了稳定阶段误报控制和快速阶段危险识别，便于在实际工程中按监测速度实时触发预警。

# 10 模型评价

本文模型的主要优点在于将数据修复、阶段识别和预警阈值放在同一逻辑链条内，避免了只依赖单一预测模型的黑箱问题；同时速度持续性准则能够减少瞬时跳变导致的误报。模型不足在于附件5中仅使用外部环境变量预测长期位移时解释度有限，说明历史位移和地质结构信息仍是提高预测性能的重要补充。


# 11 结论

问题1中，二次多项式校正模型可有效修正光纤位移计偏移，校正后R²达到0.999223。

问题2中，三段式形变转换节点为编号3346和7386，三阶段速度呈明显递增趋势。

问题3中，深部位移是表面位移变化的主控变量，孔隙水压力和累计降雨量也具有重要影响。

问题4中，分阶段梯度提升模型完成了实验集表面位移补全，预测位移随阶段推进整体增大。

问题5中，最优五变量组合为孔隙水压力、微震事件数、干湿入渗系数、爆破点距离和单段最大药量，三级预警阈值分别为4.7100、10.0440和12.8400 mm/h。
