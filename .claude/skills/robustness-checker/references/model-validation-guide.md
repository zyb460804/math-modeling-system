# 模型检验方法指南

> 模型检验是从三等奖到一等奖的关键区分器。本指南涵盖灵敏度分析、稳健性检验、误差分析和验证检查清单。

---

## 检验内容放在哪里？

实际获奖论文中，绝大多数将灵敏度分析/误差分析**嵌入在每个子问题求解末尾**（如 5.1.6 灵敏度分析），篇幅 0.5-1 页/子问题。如果所有子问题的检验内容加起来超过 2 页，可以在「模型评价与改进」章中汇总关键检验结论。

## 一、灵敏度分析（最核心，必须做）

### 1.1 局部灵敏度分析（Local Sensitivity Analysis）

**做法**：选取 3-5 个关键参数，分别改变 ±10%、±20%，观察输出变化。

**步骤**：
1. 确定关键参数（模型中的核心假设参数）
2. 对每个参数，保持其他参数不变
3. 分别测试 -20%, -10%, +10%, +20% 四种情况
4. 记录输出结果的变化幅度
5. 画成图表展示

**图表选择**：
- 龙卷风图（Tornado Diagram）：最适合展示多参数灵敏度排序
- 单参数灵敏度曲线：X轴=参数值变化，Y轴=输出结果

**解读模板**：
> 灵敏度分析结果表明，[最敏感参数]对结果的相对影响最大（变化幅度达±XX%），[次敏感参数]次之（±XX%），而[不敏感参数]的变化对结果影响极小（<±X%）。这说明模型对[最敏感参数]的估计精度要求较高，后续应用中应重点确保该参数的准确获取。

---

### 1.2 全局灵敏度分析（Global Sensitivity Analysis — Sobol' 法）

**做法**：用 Sobol' 指数量化每个参数对输出方差的独立贡献和交互贡献。

**Sobol' 指数解读**：
- **S1（一阶指数）**：参数独立解释的输出方差比例。S1 越大，该参数越重要。
- **ST（总阶指数）**：参数的独立贡献 + 所有交互贡献。ST - S1 越大，交互效应越强。
- **S2（二阶指数）**：两两参数之间的交互效应。

**Python 实现**（使用 SALib 库）：

```python
from SALib.sample import saltelli
from SALib.analyze import sobol
import numpy as np

# 定义参数范围和分布
problem = {
    'num_vars': 3,
    'names': ['param1', 'param2', 'param3'],
    'bounds': [[0.8, 1.2], [0.9, 1.1], [100, 200]]
}

# 生成参数样本
param_values = saltelli.sample(problem, 1024)  # N=1024, 总样本 N*(2D+2)

# 运行模型获取输出
Y = np.array([model(x[0], x[1], x[2]) for x in param_values])

# 计算 Sobol' 指数
Si = sobol.analyze(problem, Y)
print(f"S1 (一阶): {Si['S1']}")      # 独立贡献
print(f"ST (总阶): {Si['ST']}")      # 总贡献（含交互）
print(f"S2 (二阶交互): {Si['S2']}")   # 两两交互
```

**结果解读**：
- S1 > 0.6 表示该参数是主要驱动因素
- ST - S1 > 0.2 表示该参数有显著交互效应
- S1 < 0.05 表示该参数对输出几乎无影响

## 二、蒙特卡洛稳健性检验（Monte Carlo Robustness）

### 2.1 Monte Carlo 扰动法

**做法**：对模型输入或参数添加随机噪声，多次运行模型，观察输出的分布。

**步骤**：
1. 确定扰动变量（输入数据、关键参数）
2. 设定噪声分布（通常 N(0, σ²)，σ 可取真实值/最优值的 5-10%）
3. 随机采样 N 次（N ≥ 1000）
4. 记录每次的输出
5. 画直方图 + 报告可信区间

**解读模板**：
> 在1000次Monte Carlo仿真中，最优解在95%的情况下落在[XX, XX]区间内，表明模型对输入波动具有良好的稳定性。当参数扰动超过15%时，解的可靠性降至XX%以下，定义了模型的有效适用范围。

### 2.2 场景测试（Scenario Testing）

选择几个极端或边界场景，验证模型的合理性：

| 场景类型 | 测试内容 | 预期行为 |
|---------|---------|---------|
| 最小值场景 | 所有参数取下界 | 模型仍能给出合理解 |
| 最大值场景 | 所有参数取上界 | 模型不崩溃 |
| 单因素极端 | 仅一个参数取极端值 | 输出变化在可接受范围 |
| 边界条件 | 约束恰好满足 | 解在可行域内 |

## 三、误差分析（Error Analysis）

### 3.1 回归模型的误差分析

至少报告以下指标：

| 指标 | 公式 | 含义 |
|------|------|------|
| **MSE** | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 均方误差 |
| **RMSE** | $\sqrt{MSE}$ | 均方根误差（与因变量同量纲） |
| **MAE** | $\frac{1}{n}\sum|y_i - \hat{y}_i|$ | 平均绝对误差 |
| **R²** | $1 - \frac{SS_{res}}{SS_{tot}}$ | 决定系数（解释方差比例） |
| **MAPE** | $\frac{1}{n}\sum|\frac{y_i - \hat{y}_i}{y_i}| \times 100\%$ | 平均绝对百分比误差 |

建议增加：残差图、Q-Q 图。

**解读模板**：
> 模型的R²为0.873，RMSE为12.4，表明模型解释了87.3%的数据变异。残差分析显示残差呈随机分布（无显著模式），表明模型假设（方差齐性、线性关系）基本成立。但Q-Q图显示尾部有轻微偏离正态，可能由少数极端样本导致。

### 3.2 预测模型的误差分析

建议增加：
- MAPE（平均绝对百分比误差）
- 预测区间覆盖率（Prediction Interval Coverage Probability, PICP）
- 平均预测区间宽度（Mean Prediction Interval Width, MPIW）

### 3.3 优化模型的误差分析

讨论数值方法的截断误差、收敛判据的灵敏度。

## 四、假设验证（Assumption Validation）

回到模型假设章节，逐一验证关键假设是否在模型中成立：

| 假设类型 | 验证方法 | 判定标准 |
|---------|---------|---------|
| 线性假设 | 残差图检验 | 残差无明显模式 |
| 正态性假设 | Shapiro-Wilk 检验 | p > 0.05 |
| 独立性假设 | Durbin-Watson 检验 | DW ≈ 2（1.5-2.5 可接受） |
| 稳态假设 | 频谱分析/FFT | 功率谱无明显趋势 |
| 方差齐性 | Breusch-Pagan 检验 | p > 0.05 |

**每个假设的验证写 2-3 句话**，说明验证方法和结论。如果某个假设不成立，讨论对模型的影响程度。

---

## 五、对比验证（Comparative Validation）

### 5.1 多方法对比

用至少两种不同方法求解同一问题，对比结果的差异。

**示例**：
> 为验证优化结果的可靠性，本文将贪心算法(MAA)与模拟退火(SA)的求解结果进行对比。两种方法在5组测试数据上的平均偏差为3.2%，最大偏差为7.8%，表明贪心算法的近似解已接近全局最优。

### 5.2 回溯验证（Backtesting）

用历史数据的一个子集训练模型，预测另一个时间段，与真实值对比。美赛论文特别推荐。

## 六、验证检查清单

### 按比赛类型

| 检验方法 | 国赛最低要求 | 国赛冲高奖 | 美赛最低要求 |
|---------|------------|-----------|------------|
| 误差分析(R²/MSE) | ✓ 必做 | ✓ | ✓ 必做 |
| 残差分析 | 推荐 | ✓ | ✓ |
| 局部灵敏度(±10%) | ✓ 必做 | ✓ | ✓ 必做 |
| 龙卷风图 | 推荐 | ✓ | 推荐 |
| Sobol' 全局灵敏度 | - | 推荐 | ✓ 强烈推荐 |
| Monte Carlo 稳定性 | - | ✓ | ✓ |
| 假设验证 | 推荐 | ✓ | ✓ |
| 多方法对比 | 推荐 | ✓ | 推荐 |
| 回溯验证 | - | 推荐 | ✓ |

### 按模型类型

| 模型类型 | 必做检验 | 推荐检验 |
|---------|---------|---------|
| 预测模型 | RMSE + MAE + R² + 残差图 | MAPE + 预测区间覆盖率 + 回溯验证 |
| 优化模型 | 局部灵敏度 + 收敛曲线 | Monte Carlo + 多方法对比 |
| 评价模型 | 灵敏度分析 + 一致性检验 | Sobol' + 专家校验 |
| 分类模型 | 准确率 + 混淆矩阵 + F1 | ROC-AUC + 交叉验证 |
| 机理模型 | 假设验证 + 残差分析 | 参数溯源 + 极端场景测试 |

## 七、检验章节的标准写法

### 方式一：嵌入子问题（推荐，获奖论文最常见）

在每个子问题求解末尾加入检验小节，如：

```
5.1 问题一的模型建立与求解
5.1.1 模型选择
5.1.2 模型建立
5.1.3 参数说明
5.1.4 求解过程
5.1.5 结果分析
5.1.6 灵敏度分析  ← 嵌入此处
  [对问题一的 2-3 个关键参数做 ±10%, ±20% 测试]
  [结果表 + 1-2 句解读]
```

### 方式二：独立成章（适合检验内容丰富时）

```
五、模型检验

5.1 误差分析
[问题一误差分析：MSE/R² + 残差分析]
[问题二误差分析：相对误差 + 参数敏感性]

5.2 灵敏度分析
5.2.1 关键参数识别
5.2.2 参数灵敏度测试
[±10%, ±20% 的变化结果表格 + 龙卷风图]

5.3 稳定性分析
[Monte Carlo 扰动结果 + 可靠度曲线]
```

### 美赛独立章写法

```
X. Sensitivity Analysis

X.1 Global Sensitivity Analysis (Sobol' Indices)
[Sobol' 分析结果 + 解读]

X.2 Parameter Robustness
[参数区间测试 + 弹性系数表 + 图]

X.3 Uncertainty Quantification
[Bootstrap/Monte Carlo + 覆盖率验证]

X.4 Scenario Testing
[极端场景测试]
```
