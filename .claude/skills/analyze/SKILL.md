# /analyze — 统一审题选模入口

> **核心原则**：同一意图 → 默认最深输出。"审题""选模""推荐模型""建模路线"均拿到相同全量报告。

## 触发词（统一入口）

以下触发词**全部**路由到本 skill：`审题` `选模` `推荐模型` `用什么算法` `模型选择` `建模路线`

## 架构

```
用户说任何审题/选模相关触发词
        │
        ▼
  ┌─────────────────────────┐
  │  /analyze（本 skill）     │
  │  统一入口                │
  └──────┬──────────────────┘
         │
         ├──► 阶段1: 题型判断 + 子问题关系 + 最终输出定义
         ├──► 阶段2: Top 3 模型路线 + 优劣比较 + 组合建议
         ├──► 阶段3: 代码模板路径 + 运行命令
         ├──► 阶段4: 风险预警（数据/算法/可复现/答辩）
         └──► 阶段5: 最小检验包 + 写作落点建议
```

## 工作流

### Step 1: 题型判断

读取赛题文件（`problem_files/`），对齐以下知识库：
- `outputs/problem_type_taxonomy.md` — 题型分类学
- `outputs/method_matching.md` — 方法匹配表（11类任务×模型×算法×风险）
- `outputs/model_selection_flow.md` — 选模流程
- `outputs/model_selection_quick_table.md` — 快速选型表

输出：
- 主题型 + 辅助题型
- 子问题关系（先后关系、服务关系）
- 每个子问题的最终输出定义
- 常见误判提示

### Step 2: 模型路线推荐

读取：
- `outputs/method_matching.md`
- `outputs/algorithm_templates.md`

输出 Top 3 推荐方案：

| 排名 | 模型 | 算法 | 优势 | 风险 | 代码模板 |
|------|------|------|------|------|----------|
| 1 | | | | | resources/04_代码模板/... |
| 2 | | | | | ... |
| 3 | | | | | ... |

### Step 3: 组合建议

- 主模型：[X] — [理由]
- 辅助模型：[Y] — [理由]
- 验证方法：[Z]
- 职责分工说明

### Step 4: 风险预警

从 `outputs/model_specific_pitfalls.md` 提取：
- 数据风险
- 算法风险
- 可复现风险
- 答辩风险

### Step 5: 最小检验包 + 写作落点

按题型输出最小应补的检验，以及各模型在论文中的写作位置。

```markdown
### 五、最小检验包 + 写作落点

- 运行代码：参考代码模板路径
- 获取图表方案：走 /figure
```

## 前置依赖

- 题型分类学：`outputs/problem_type_taxonomy.md`
- 方法匹配表：`outputs/method_matching.md`
- 选模流程：`outputs/model_selection_flow.md`
- 快速选型表：`outputs/model_selection_quick_table.md`
- 算法模板：`outputs/algorithm_templates.md`

## 约束

- 不编造算法，只推荐知识库中已有的方案
- 明确标注每个推荐的风险等级（低/中/高）
- 如果题型不确定，给出 2-3 种可能的题型判断

## 系统同步说明

任务路由 → 知识更新/资料入库 → 单题开工 → 数据理解 → 审题选模 → 代码/论文/图表/表格生产 → 动态验收 → 最终质量门 → 提交/答辩 → 经验回灌。
