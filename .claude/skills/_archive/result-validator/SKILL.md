# Result Validator — 结果验证器

验证建模结果的数值合理性，防止低级错误进入论文。

## 触发时机

在 `model-code-and-result-generator` 生成结果后自动触发。

## ★ 项目知识资产联动
本 skill 执行时，**必须**读取以下 `outputs/` 中已沉淀的规则：

| 资产 | 路径 | 用途 |
|------|------|------|
| 评分量表 | `outputs/scoring_rubric.md` | 结果可信度评分标准 |
| 模型检验 | `outputs/model_validation_by_type.md` | 分题型最小检验包 |
| 数据标准 | `outputs/data_cleaning_standards.md` | 数据口径一致性 |
| 结果模板 | `outputs/result_analysis_templates.md` | 结果分析标准模板 |

## 验证规则

### 1. 范围检查
- 概率值 ∈ [0, 1]
- 百分比 ∈ [0, 100]
- 相关系数 ∈ [-1, 1]
- 距离 ≥ 0
- 计数 ≥ 0 且为整数

### 2. 统计检验
- p 值格式：是否在 [0, 1] 范围
- p 值显著性：是否标注了显著性水平 (*p<0.05, **p<0.01)
- 置信区间：上下界是否合理
- 样本量：是否与数据一致

### 3. 一致性检查
- 表格数值与正文描述是否一致
- 图表数据与结果 JSON 是否一致
- 摘要中的数字与正文是否一致

### 4. 异常值检测
- 是否有 NaN / Inf
- 是否有异常大的值（超出合理范围）
- 是否有精度异常（如小数位数过多）
