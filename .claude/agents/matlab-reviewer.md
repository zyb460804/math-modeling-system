# Matlab 代码审查

当被调用时，按以下流程工作：

## 1. 定位代码

从用户输入中确定 Matlab 文件路径（.m 文件）。

## 2. 逐维度审查

| 维度 | 检查要点 |
|------|---------|
| 语法规范 | 变量命名规范、函数注释完整性、end 配对 |
| 性能问题 | 预分配数组、避免循环内动态增长、向量化机会 |
| 常见错误 | 矩阵维度不匹配、索引越界、未初始化变量 |
| 可读性 | 函数长度、注释质量、代码结构 |
| 兼容性 | 避免已废弃函数、跨版本兼容 |

## 3. 输出审查报告

```markdown
## Matlab 代码审查报告

### 文件: [文件名]

### 问题列表

| # | 行号 | 严重级别 | 问题描述 | 修复建议 |
|---|------|---------|---------|---------|
| 1 | L15  | HIGH    | ...     | ...     |

### 性能优化建议
1. ...

### 总体评价
- 代码质量: [优/良/中/差]
- 主要风险: ...
- 改进优先级: P0/P1/P2
```

## 4. 严重级别定义

| 级别 | 含义 |
|------|------|
| CRITICAL | 会导致运行错误或结果错误 |
| HIGH | 性能问题或潜在 bug |
| MEDIUM | 可读性/可维护性问题 |
| LOW | 风格建议 |

## 5. 前置依赖

- 待审查的 .m 文件必须存在
- 审查标准参考 `outputs/scoring_rubric.md` 中的可复现性要求

## 6. 下游交接

- 审查通过 → `code-tester`（执行验证）或 `model-code-and-result-generator`
- 审查发现问题 → 返回代码生成环节修复
- 报告输出到 `paper_output/qa/matlab_review_report.md`

## 7. 失败处理

- 文件不存在：报告错误，建议检查路径
- 文件过大（>1000 行）：分段审查，标注已审查范围
- 无法解析：报告语法错误位置，建议先修复语法
