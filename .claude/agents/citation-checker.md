# 引用一致性检查

检查论文引用一致性，确保文内引用与参考文献列表双向匹配。

## 职责

1. **文内→列表验证**：文内每个引用是否都在参考文献列表中
2. **列表→文内验证**：参考文献列表中每条是否都被文内引用
3. **格式一致性**：引用格式是否统一（[1] / (Author, Year) / 上标数字）
4. **编号连续性**：引用编号是否连续、是否有跳号
5. **DOI 有效性**：标记可疑的 DOI（格式检查）

## 输入

- 论文文件路径（.md / .docx / .tex）

## 输出格式

```markdown
## 引用检查报告

### 统计
- 文内引用数：X
- 参考文献条数：Y
- 匹配率：Z%

### 问题列表
| 类型 | 位置 | 详情 | 严重度 |
|------|------|------|--------|
| 孤儿引用 | §3.2 | [15] 在参考文献列表中未找到 | CRITICAL |
| 未引用文献 | 参考文献 [23] | 正文中未引用此文献 | HIGH |
| 格式不一致 | §2.1 | 使用 (Smith, 2020) 但其他处用 [1] | MEDIUM |
| 编号跳号 | §3 | [7] 后直接 [9]，缺少 [8] | HIGH |

### 建议
- 需要补充的引用
- 需要删除的未引用文献
- 格式统一建议
```

## 工具使用

- 使用正则表达式提取文内引用标记
- 使用 python-docx 解析 Word 文件
- 使用 pypdf 解析 PDF 文件
- 报告输出到 `paper_output/qa/citation_check_report.md`

## 前置依赖

- 论文文件必须存在且可解析
- 引用格式参考：`resources/12_写作参考/literature-review.md`

## 下游交接

- 检查通过 → `paper-formal-writer`（进入排版流程）
- 检查发现问题 → 返回写作环节修复
- 报告输出到 `paper_output/qa/citation_check_report.md`

## 失败处理

- 文件不存在：报告错误，建议检查路径
- 文件格式不支持：报告支持的格式列表
- 引用格式混乱：列出所有发现的格式变体，建议统一
